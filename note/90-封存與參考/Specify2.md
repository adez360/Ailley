# 村莊模擬 — 村民系統設計文件 v2

> **v1 → v2 的核心變更**：指標不再是「行為決策表」，而是拆成 **感官 / 裁決 / 儀表** 三種角色。
決策權完整交給 LLM，引擎只負責 **事實** 與 **結果**。
> 

---

## 0. 變更摘要

| 項目 | v1 寫法 | v2 修正 |
| --- | --- | --- |
| 六大個性參數 | 每 tick 浮動，直接決定行為（高勤勉→打獵） | 靜態人格，轉成自然語言寫進 system prompt；**只在睡眠反思時微調** |
| 12 種狀態 | 生理與情緒混在一起 | 切成 **引擎裁決的客觀狀態** 與 **LLM 自我宣告的主觀情緒** |
| 指標用途 | 行為查表 | ① State Snapshot（LLM 的體感）② Guardrail（硬裁決）③ Telemetry（觀察儀表） |
| 好感度 | 全體從 0 開始 | 開局隨機發放愛恨矩陣 |
| 活動度 | 未處理 | 新增 **無聊度**、idle 上限、待機代價、縮短移動距離 |
| 互動清單 | 無溝通動作 | 新增 **說話 / 喊話**（否則「抓捕需兩人」在機制上不可能達成） |

## 1. 核心契約：LLM 有意圖權，引擎有結果權

```
┌──────────────────────────────────────────────────────────────┐
│                        引擎 (Godot)                          │
│  世界事實 · 物理 · 經濟 · 傷病 · 庫存 · 好感度數值 · 時間     │
└───────┬──────────────────────────────────────────▲───────────┘
        │ ① State Snapshot（我是誰／我現在如何／我看到誰）      │
        │                                                      │
        ▼                                          ③ 裁決結果   │
┌──────────────────────────────────────────────────────────────┐
│                    村民 LLM（每人一顆）                        │
│  ② 輸出：intent + emotion + speech + 內心獨白                 │
└──────────────────────────────────────────────────────────────┘
        │
        ▼
┌──────────────────────────────────────────────────────────────┐
│                    ④ Telemetry（數值曲線 + log）              │
│      供你回放因果鏈：飢餓 92 → 存款 0 → 偷竊                  │
└──────────────────────────────────────────────────────────────┘
```

### 指標的三個角色

1. **感官（State Snapshot）**
LLM 沒有身體。不把「飢餓度 87、右手割傷、金錢 12」塞進 prompt，它不會知道自己餓了，還會宣稱身上有一千塊。指標是它唯一的體感來源。
2. **硬裁決（Guardrail）**
LLM 說「我沒受傷、我要跑」→ 引擎看 `bleeding = true`，直接駁回，強制降速。
LLM 說「我買威士忌」→ 引擎看 `money = 12`，駁回並回傳失敗原因。
3. **觀察儀表（Telemetry）**
純看文字 log 只看得到「他去偷了東西」，看不出為什麼。
有數值曲線才能回放：`飢餓度 92 → 情緒穩定崩 → 觸發偷竊`。
**沒有指標，這個專案就沒有可觀測的實驗數據，只剩一堆看起來很像的對話。**

## 2. 世界：地點與設施

> 設計方針：**地圖要小、設施要密**。10 個村民若有 70% 時間在走路，觀察畫面會非常空。
建議任兩個設施的步行時間 ≤ 2 tick。
> 

### 2.1 生活區

| 設施 | 功能 | 容量 |
| --- | --- | --- |
| 家 | 睡覺、物品收納（衣服、錢財、魚、獵物、草藥、樂器） | 1（可被偷竊） |
| 餐酒館 | 進食、飲酒、收購獵物與水生動物 | 無上限 |

**食物**：紅酒燉牛肉、雜菜燴飯、拉麵、生魚片、漢堡王、稀飯、地瓜、水煮雞胸肉、雜糧饅頭
**飲品**：珍珠奶茶、紅茶、能量飲料、白開水、威士忌、長島冰茶、小麥啤酒、蛋白飲

### 2.2 休息區

| 設施 | 功能 | 容量 |
| --- | --- | --- |
| 涼亭 | 乘涼 | — |
| 湖泊 | 釣魚、觀賞景致 | 4 |
| 長椅 | 休憩 | 2 |

### 2.3 資源採集與風險區

| 場域 | 產出 | 風險 | 體力 | 收益 |
| --- | --- | --- | --- | --- |
| 森林捕獵（牛、狼） | 高價獵物 | 高機率 **流血** | 高 | 高 |
| 森林捕獵（野兔、鼴鼠、野雞、野雞蛋） | 低價獵物 | 高機率 **扭到腳** | 中 | 中低 |
| 藥草叢 | 草藥 | 易 **割傷手** | 低 | 低 |

**怪物襲擊事件**：白天低機率、夜晚高機率。引擎只負責「發生襲擊」這個事實與傷害結果；**受襲後是驚恐還是憤怒，由該村民的 LLM 自行宣告**。

### 2.4 城鎮設施

| 設施 | 功能 |
| --- | --- |
| 服裝鋪 | 購買衣物 |
| 藥草鋪 | 醫治傷病、收購草藥 |
| 布告欄 | 事件發布（**未開放**） |
| 洗心革面所 | 入獄反省（自首或被抓捕者）、出獄 |
| 結婚禮堂 | 結婚、離婚 |
| 甘道夫石 | 移動、參拜、供奉、吐口水、說話、站至上方 |

## 3. 村民資料模型（四層）

```
Layer 1 人格層 ── 靜態．寫進 system prompt．只在睡眠反思時微調
Layer 2 生理層 ── 引擎裁決．客觀．不可被 AI 幻覺竄改
Layer 3 關係層 ── 引擎計算．好感度矩陣
Layer 4 情緒層 ── LLM 自我宣告．主觀．因人而異
```

### 3.1 Layer 1：人格層（六大參數，0–100）

**不再每 tick 變動。** 每回合抖動人格會讓角色前後矛盾，觀察價值歸零。
數值只做兩件事：① 開局時**轉譯成自然語言**寫進 system prompt ② 存進 log 供你分析。

| 參數 | 高（≥70）敘述範例 | 低（≤30）敘述範例 |
| --- | --- | --- |
| 勤勉度 | 「你閒不下來，看別人發呆會覺得浪費生命。」 | 「你能不動就不動，寧可餓一點也不想爬起來工作。」 |
| 膽識度 | 「你不怕森林深處，危險反而讓你興奮。」 | 「你天生膽小，寧可繞路也不靠近有聲音的地方。」 |
| 社交性 | 「你看到人就想搭話，獨處會讓你煩躁。」 | 「你不喜歡人多，能一個人待著最好。」 |
| 道德感 | 「你受不了不守規矩的人，看到就想舉報。」 | 「規則對你來說只是建議，只要拿得到手就是你的。」 |
| 情緒穩定 | 「你很難被激怒，事情發生了先想再說。」 | 「你一點就著，小摩擦也會讓你失控。」 |
| 浪漫藝術 | 「你相信生活需要音樂與愛，沒有這些活著沒意思。」 | 「你覺得表演和調情都是浪費時間。」 |

> **注意**：人格參數**不參與任何引擎機率運算**（不影響命中率、不影響成功率）。
它只影響 LLM 怎麼想。這樣你才能乾淨地觀察「人格 → 語言 → 行為」的傳導，而不會被引擎的隱藏加權汙染。
> 

**唯一的變動入口**：睡眠反思（見 §8），且單晚變動上限 ±3。

---

### 3.2 Layer 2：生理層（引擎裁決 · 客觀）

| 欄位 | 範圍 | 說明 |  |  |
| --- | --- | --- | --- | --- |
| `hunger` | 0–100 | 過高 → 移動速度下降、工作效率下降 |  |  |
| `thirst` | 0–100 | 過高 → 移動速度下降 |  |  |
| `stamina` | 0–100 | 歸零 → 強制中止工作 |  |  |
| `money` | int | 買不起就是買不起，無協商空間 |  |  |
| `boredom` | 0–100 | **新增**，見 §7 |  |  |
| `bleeding` | bool | 捕獵牛/狼失敗；體力持續流失、**禁止奔跑** | 捕獵失敗有可能被反殺嗎 |  |
| `sprained_ankle` | bool | 捕獵小型動物失敗；大幅降速、禁止奔跑 |  |  |
| `hand_cut` | bool | 採集意外；打獵與演奏效率下降 |  |  |
| `incarcerated` | bool | 位於洗心革面所內，行動受限 |  |  |
| `ex_convict` | 剩餘 tick 數 | 出獄後短期狀態，其他村民對其好感度微幅扣減 |  |  |
| `vigilant` | bool | 執行巡邏/觀察時由引擎開啟，擴大偵測範圍 |  |  |
| `inventory[]` | — | 含**腐壞率**（食材/獵物/魚/草藥）與**耐久度**（樂器） |  |  |

<aside>
💡

</aside>

**這些欄位必須決定性、可驗證、不可被 AI 宣告改變。**
LLM 不能說「我的傷好了」，只有藥草鋪能治好。

### 3.3 Layer 3：關係層（好感度矩陣，−100 ~ +100）

由引擎依事件決定性計算，LLM 不能直接改寫。

| 區間 | 標籤 | 對 LLM 的敘述 |
| --- | --- | --- |
| 80 ~ 100 | 摯愛 / 至交 | 「你願意為他擋刀。」 |
| 20 ~ 79 | 友好 | 「你挺喜歡他的。」 |
| −19 ~ 19 | 中立 | 「你對他沒什麼特別感覺。」 |
| −20 ~ −79 | 嫌隙 | 「你看他不太順眼。」 |
| −80 ~ −100 | 死敵 | 「你恨他。」 |

**開局不要全設 0。** 隨機發放愛恨矩陣（例如：每人隨機 1 位 ≥60、1 位 ≤−60、其餘 −20~20），第一天就有摩擦，不用等三十分鐘暖機。

**變動規則（範例，可調）**
| 事件 | Δ |
|—|—|
| 互動被接受（握手/擁抱） | +3 / +6 |
| 收到禮物或捐款 | +8 |
| 互動被拒絕 | −4 |
| 被偷竊 / 被搶劫 | −25 / −40 |
| 樂器被破壞 | −45 |
| 被攻擊 | −35 |
| 被舉報抓捕 | −30 |
| 目擊他人犯罪（旁觀者） | −10 |
| 同場共處且無衝突（每 10 tick） | +1 |

---

### 3.4 Layer 4：情緒層（LLM 宣告 · 主觀）

**這是 v1 最該修正的地方。**
引擎只給**事件**（「B 砸壞了你的樂器」），LLM 輸出 `emotion` + 內心獨白 + 下一步動作。
同一件事該生氣還是難過，本來就該由角色個性決定——高情緒穩定的角色可能回 `sad` 然後走開，**這正是你要觀察的東西**。

**情緒 enum**：`excited` / `happy` / `in_love` / `terrified` / `burnout` / `angry` / `sad` / `neutral`

情緒的作用：
- 回寫進下一 tick 的 Snapshot（角色記得自己剛才在生氣）
- 進 log，作為觀察資料
- **不**直接改變引擎數值（唯一例外：`in_love` 允許解鎖結婚禮堂互動選項）
- 預設持續 5 tick 後自動衰減回 `neutral`，除非 LLM 再次宣告

> 對照：`burnout` 是主觀宣告，`stamina = 4` 是客觀事實。體力見底時 LLM 可能宣告 burnout 也可能硬撐，這個差異就是人格的表現。
>

## 4. State Snapshot（每 tick 餵進 prompt 的內容）

```
【現在】第 3 天 19:40（夜晚）
【你的身體】飢餓 87（很餓） 口渴 41 體力 22（快沒力了） 無聊 12
【傷病】右手割傷（打獵與演奏效率下降）
【錢包】12 元
【背包】草藥 x3（明早腐壞）、木笛（耐久 60%）
【位置】村莊廣場，靠近餐酒館
【你看得到】
  - 阿蘭（在長椅上，看起來在發呆）你恨她
  - 老周（正在演奏，前科犯）你對他沒什麼特別感覺
【剛剛發生】老周開始演奏，路過的人丟了錢給他
【你上一刻的心情】angry
【上一個動作結果】前往藥草鋪 → 失敗：錢不足（需 40 元）
【可用動作】見 Action Schema
```

原則：
- 用**自然語言 + 括號註記**，不要只丟裸數字（LLM 對「87」沒感覺，對「很餓」有）
- 一定要回報**上一個動作的結果**，包含失敗原因，否則 LLM 會不斷重複無效動作
- 只給視野內的資訊，不要全知

## 5. Action Schema（LLM 輸出）

```json
{
  "emotion": "angry",
  "inner_monologue": "沒錢治手，草藥明天就爛了。老周那邊有現金。",
  "speech": "喂，老周，你那笛子借我吹一段。",
  "speech_volume": "normal",
  "intent": {
    "action": "perform",
    "target": null,
    "location": "村莊廣場"
  }
}
```

### 動作分類

**A. 溝通（新增，觀察導向最有價值的行為）**`speak`（對特定對象）、`shout`（範圍廣播）、`whisper`（僅目標可聽）

> 沒有溝通機制，「抓捕需兩名村民」這條規則在機制上根本無法達成。
加入喊話後，抓捕會自然演化出「呼叫幫手 → 對方回應 → 兩人合圍」的鏈條，這是最好看的觀察素材。
> 

**B. 需對方同意**
握手、擁抱、送禮、給錢、結婚、離婚

**C. 單方施加（引擎判定成敗，不需同意）**
偷竊、搶劫、破壞樂器、攻擊、抓捕（需兩人）、舉報

**D. 工作 / 經濟**
森林打獵、藥草採集、釣魚、隨地表演、買賣、治療、進食、飲酒

**E. 移動 / 體態**
移動、奔跑、蹲下、抱頭、舉手、大叫、摔物品、飛吻、跟隨、展示物品、觀察/巡邏、自首、睡覺、`idle`

> **無預設職業綁定**：村民依自身狀態自由選擇工作，引擎不指派職業。
>

## 6. 引擎裁決表（Guardrail）

| LLM 意圖 | 引擎條件 | 裁決 |
| --- | --- | --- |
| `run` | `bleeding` 或 `sprained_ankle` | **駁回** → 改為 walk，回傳「你跑不動」 |
| 購買 / 點餐 | `money < price` | **駁回** → 回傳金額差 |
| 使用物品 | 不在 `inventory` | **駁回** → 回傳「你身上沒有這個」 |
| 進入湖泊 / 長椅 | 已達容量（4 / 2） | **駁回** → 回傳「位置滿了」 |
| 打獵 | `stamina < 20` | **駁回** → 強制中止 |
| 抓捕 | 未有第二人於同 tick 對同目標宣告抓捕 | **失敗** → 目標可反擊或逃跑 |
| 需同意的互動 | 目標下一 tick 未回 `accept` | **失敗** → 發起方好感度 −4 |
| 治療 | 不在藥草鋪 / 錢不足 | **駁回** |
| `idle` | 已連續 3 tick | **駁回** → 強制重新決策，且本次不接受 idle |
| 任何自述狀態的宣告 | 與生理層衝突 | **忽略宣告**，以引擎數值為準 |

**原則：LLM 的宣告永遠只是「意圖」。引擎不爭論，只回傳結果。**

## 7. 活動度設計：如何逼出分歧

LLM 天生會收斂到「合理但無聊」——十個角色都會理性地吃飯、工作、睡覺，看起來像同一個人。必須靠設計逼出分歧。

### 7.1 讓待機有代價

- 飢餓 / 口渴衰減率調快（建議：滿值 → 危險值約 40 tick）
- 獵物 / 魚 / 草藥腐壞率高（隔夜即腐）→ 逼即時交易，不能囤
- 樂器耐久度會掉 → 演奏者必須持續賺錢維修
- **閒著就會餓、就會窮。**

### 7.2 禁止長時間 idle

`idle` 連續上限 3 tick，超過即強制重新決策並移除 idle 選項。

### 7.3 新增參數：無聊度 / 刺激需求（`boredom`）

> **這是專為觀察導向而生的活動度引擎。** 沒有它，村民很容易卡在最佳解迴圈（打獵→吃飯→睡覺）跑一整局。
> 

| 規則 | 值 |
| --- | --- |
| 每 tick 上升 | +2 |
| 重複同一動作（連續） | 額外 +3 |
| 與**今天尚未互動過的人**互動 | −25 |
| 前往**今天尚未去過的地點** | −15 |
| 執行**今天尚未做過的動作類型** | −10 |
| 目擊衝突 / 犯罪 / 表演 | −10 |

Snapshot 注入強度：
- `boredom ≥ 60`：「你覺得今天很無聊，一直重複做一樣的事讓你煩躁。」
- `boredom ≥ 85`：「你受不了了，你必須去做點沒做過的事，或去找還沒說過話的人。」

### 7.4 開局即有摩擦

隨機愛恨矩陣（見 §3.3），第一天就會出事。

### 7.5 縮短移動距離

地圖小、設施密。任兩設施步行 ≤ 2 tick。

### 7.6 加入溝通動作

見 §5-A。這是活動度密度最高、最好觀察的行為類型。

## 8. 睡眠反思迴圈（人格微調的唯一入口）

村民睡覺時觸發一次額外的 LLM 呼叫：

**輸入**：今日事件摘要（自己的動作 + 結果 + 遭遇 + 好感度變化）
**輸出**：

```json
{
  "reflection": "我今天為了吃飯偷了東西，我不喜歡這樣的自己。",
  "personality_delta": { "morality": +2, "bravery": -1 },
  "long_term_memory": "阿蘭看到我偷東西了，她大概不會再理我。"
}
```

規則：
- 單項變動上限 ±3，單晚總變動上限 ±6
- 變動後**重新渲染 system prompt 的人格敘述**
- `long_term_memory` 進入該村民的長期記憶，之後每次 Snapshot 附帶最近 N 條

> 這是唯一允許人格漂移的地方。它讓「長期挨餓的人真的會變得比較沒有道德」這件事發生得緩慢、可追溯、可解釋。
> 

### 同儕感染（保留 v1 概念，改為緩慢版）

長期與高道德感、高情緒穩定的村民正向互動（擁抱、送禮、共處），會在**睡眠反思的輸入摘要中被強調**，讓 LLM 自己決定要不要修正。引擎不直接改人格。

## 9. Telemetry：你要記什麼

每 tick 每村民記一列：

```
tick, villager_id, hunger, thirst, stamina, money, boredom,
bleeding, sprained, hand_cut, emotion,
action_intent, action_result, target, location,
affection_deltas, speech_text, inner_monologue
```

每晚記一列：`personality snapshot + reflection + delta`

**觀察工具最低需求**
1. 單一村民的多指標時間曲線（可疊圖）
2. 事件標記（犯罪 / 受傷 / 結婚 / 入獄 標在時間軸上）
3. 好感度矩陣熱力圖（逐日快照）
4. 因果回放：點擊「偷竊」事件 → 自動往回 20 tick 展開該村民所有指標與獨白

沒有第 4 項，你就只能靠肉眼讀 log，實驗結論會無法佐證。
