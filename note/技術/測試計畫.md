# 測試計畫

模組化手動測試 checklist，見《99》P-61 拍板：由工程師手動測試玩法是否通順、功能是否
正常，依 **gameplay flow** 拆模組，不是依系統拆——自動化回歸測試已經是依系統拆（角色
數值／記憶／地點行動／社交／化身者／死亡系統，見《17》「自動化回歸測試」），這裡要抓
的是系統跟系統銜接處「順不順、LLM 講話自然不自然、UI 對不對」，兩者互補不是重複。

每個模組的通過標準都是雙軌：

- **功能面**：跑得起來，沒有 crash、卡死、資料遺失
- **體驗面**：流程順不順、LLM 回應自然不自然、UI 顯示對不對、有沒有讓人等到不耐煩的空檔

下面模組清單隨 MVP 功能進度增減，不是寫死的最終版——某模組還沒實作完就先跳過，等
功能完工再測。

## 執行方式

- **模組自測**：某模組的功能實作完成時，該功能的開發者自己先跑一次那個模組的
  checklist，盡早抓明顯問題，不用等全部功能收尾才測——不掛獨立 issue，是每個功能 PR
  收尾的一部分
- **端到端總驗收**：全部 MVP 功能收尾、展示前，由你依序跑完全部模組當最後一輪驗收，
  追蹤於 **issue #636**。跟《99》P-43（上架前 QA checklist）精神類似但不是同一份——
  這是「demo 前」，P-43 是「正式上架前」，範圍與簽核對象都不同

## 模組 1：建角與角色庫

- [ ] 建角面板三分頁（基本／個性／外觀）都能正常填寫、切換不遺失已填內容
- [ ] 決策來源欄位（Local／Cloud／Human）三選都能選、存檔
- [ ] 隨機範例按鈕能從 50 個模板庫抽出內容
- [ ] 造型組挑選（6 套固定造型）預覽跟實際套用一致
- [ ] 存檔驗證式擋掉不合法輸入（極端值、必填留空）
- [ ] 角色庫首頁能看到已建立的角色，投放到世界後正確出現在場上

## 模組 2：日常行動

- [ ] 移動／尋徑：點擊目標能正常走過去，不卡地形、不穿牆
- [ ] 工作站：`work` 開始計時、時間到給報酬，`MoneyPopup` 正確顯示
- [ ] 打獵（森林）／採集（藥草叢）：走到資源旁能觸發、成功率判定有感覺在運作、成功後拿到對應物品
- [ ] 表演：`instrument` 觸發、天神打賞 UI 可操作、路人 NPC 的打賞反應看起來像 AI 自己的決定（不是每次金額都一樣）
- [ ] 進食／飲用：`eat`／`drink` 正確消耗背包物品、生理值變化符合預期
- [ ] 購物（餐酒館／藥草鋪）：走近觸發、選單開關正常、扣款與拿到物品同步、走遠自動關閉選單
- [ ] 天神之石：輸入框開關、事實句廣播、地點事件記錄可查看

## 模組 3：社交

- [ ] `talk`／`persuade`／`give`／`shout`／`murmur` 各自能觸發、對象反應合理
- [ ] `persuade` 對玩家發起時彈窗 Y/N 正常
- [ ] `appointment` 約定機制成立後確實出現在 `today_plan`
- [ ] 對話氣泡排版正常，不重疊、不跑版
- [ ] 「思考中」過渡提示在等待 LLM 回應期間有顯示（若已實作）

## 模組 4：化身者（Player）專屬

- [ ] 建角時純 AI 欄位（`words_to_creator` 等）正確跳過，不出現在玩家流程
- [ ] `give`／`attack`／`shout` 能以玩家角色為目標，NPC 反應正常
- [ ] 天神之石在化身後的行為調整（說話功能鎖住、改查看地點事件記錄）
- [ ] 玩家死亡／重生流程跟 NPC 不對稱規則表現一致
- [ ] 六種玩家狀態小圖標（死亡／昏迷／送醫／復活／被攻擊／被搬運，若已實作）正確觸發顯示

## 模組 5：死亡與墓園

- [ ] 昏迷 30 分鐘無人搬走，正確轉入真正死亡（不是舊的自動送醫結局）
- [ ] 安葬（`bury`）流程正常，墓碑出現在墓園
- [ ] `corpse_decay` 達 100 時無名碑自動立碑
- [ ] 墓園滿 6 格時正確拒絕新安葬（MVP 簡化版行為，不是動態擴張）

## 模組 6：存讀檔與模式切換

- [ ] 存檔／讀檔（Continue）角色與世界資料正確保留
- [ ] `DecisionProvider` 三種模式（Local／Cloud／Human）都能正常驅動角色決策
- [ ] 讀檔後角色行為（`today_plan`、關係、記憶）看起來延續前次進度，不是重置
