# 建角面板

規格書 05 的「個性」分頁。版面約束見 [[UI 版面與素材規格]]。

## 現在做到哪

**只做面板與互動**，按下儲存時把 Dictionary 丟出 `character_saved` 訊號。
`hexaco_to_personality()` / `build_system_prompt()` 那條轉換管線不在這裡——
它在 `Personality`，見 [[人格與 System Prompt]]。**面板還沒接上那條管線**：
目前吃 `hexaco` 的是 `npc_schedule.json` 的 `identities`，面板丟出來的
Dictionary 沒有任何地方接。

| 分頁 | 狀態 |
| --- | --- |
| 基本（姓名／年齡／性別） | 按鈕在，`disabled` |
| **個性**（六維滑桿 + 自由文本） | **已實作** |
| 外觀 | 按鈕在，`disabled`；規格本身仍是【待規劃】 |

**還沒接進遊戲。** 場景存在但沒有任何地方會開它 —— 規格裡它是從「角色庫首頁」進去的，
而角色庫還不存在。要試的話直接跑 `scenes/character_create.tscn`，再呼叫 `open()`。

## 公開介面

- `open()` / `close()` —— 顯示與隱藏。Esc 也會關
- `collect() -> Dictionary` —— 目前的面板內容
- `character_saved(data: Dictionary)` —— 通過驗證後送出。六個 `hex_*` 欄位 + `character`
- `closed()`

## 為什麼整個面板在程式碼裡組

六個維度的列完全同構，拉在場景裡就是六份複製，增減一個維度要改六處。
現在由 `DIMENSIONS` 表驅動生成，那張表同時也是「面板上的順序」與「翻譯 key 的來源」——
兩端標籤的 key 是主 key 加 `_LO` / `_HI`，不必另外列。

## 存檔驗證（規格 4-4）

極端項 = 滑桿 ≤25 或 ≥75。門檻**依 `character` 有沒有填而不同**：

| `character` | 需要的極端項 |
| --- | --- |
| 有填 | 2 ~ 4 |
| 留空 | 3 ~ 4 |

留空時要求更多，否則會產生一個既沒數值特徵也沒文字描述的空角色。
不達標時 `儲存` 按鈕 `disabled`，不是按下去才報錯。

實測過的五種狀態：0 極端無描述 → 鎖；2 極端無描述 → 仍鎖（門檻是 3）；
2 極端有描述 → 開；5 極端 → 鎖並提示減少；4 極端 → 開。

## 兩個實作上的坑

**`TextEdit` 沒有 `max_length`。** 250 字上限只能在 `text_changed` 裡自己截，
而且截字會把游標彈到開頭，要先記下 `get_caret_column()` 再設回去。

**極端狀態的紅色填充是 `add_theme_stylebox_override`，不是 theme variation。**
variation 必須註冊 base type，而那只有編輯器 UI 做得到（`theme_manage` 沒有對應的 op）。
`儲存` 按鈕的 Amber 底同理。這兩處之後可以收進 theme，但要手動補 base type。

**HSlider 的滑鈕是 icon 不是 StyleBox**，所以 `assets/ui/slider_grabber.png` 是必要的，
不是裝飾。目前是 5×11 的佔位圖（Bark 外框 + Cream 內芯），畫好真的直接覆蓋同一個檔名即可。
