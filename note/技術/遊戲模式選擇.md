# 遊戲模式選擇

開場選單（`MainMenu.tscn`）讓玩家選要用哪種模式進遊戲，或是讀檔。
選完就切到 [[尋徑與 Debug 主控台|main.tscn]]。

## 檔案

| 檔案 | 角色 |
| --- | --- |
| `scenes/MainMenu.tscn` | 選單畫面，`MOD1` / `MOD2` / `LOADING` 三顆 `Button` |
| `scripts/ui/main_menu.gd` | 掛在 `MainMenu.tscn` 根節點，接三顆按鈕的 `pressed` |
| `scripts/core/Global.gd` | autoload `Global`，存 `current_mode`，遊戲裡任何地方都能讀 |

## API

```gdscript
Global.current_mode: Global.GameMode   # PLAYER_VS_AI / PLAYER_AI_VS_AI
Global.load_game() -> void             # 存檔邏輯還沒做，目前只印 log
Global.save_game() -> void             # 還沒做
```

## 流程

按下 `MOD1` → `_on_mod_1_pressed()` 把 `Global.current_mode` 設成
`PLAYER_VS_AI` → `change_scene_to_file("res://scenes/main.tscn")`。
`MOD2` 一樣的流程但設成 `PLAYER_AI_VS_AI`。`LOADING` 則是先呼叫
`Global.load_game()` 再切場景。

`main.tscn` 那邊的系統要分流的話，讀 `Global.current_mode` 就好，
不用另外傳參數或找 MainMenu 要資料 —— 這是它做成 autoload 的原因。

## 怎麼加一個新模式

1. `Global.gd` 的 `GameMode` enum 加一個值。
2. `MainMenu.tscn` 加一顆 `Button`，signal `pressed` 接到
   `main_menu.gd` 一個新的 `_on_xxx_pressed()`。
3. 新方法裡把 `Global.current_mode` 設成新值，一樣呼叫
   `change_scene_to_file(GAME_SCENE_PATH)`。
4. 需要分流的系統（例如某個角色的行為邏輯）自己 `match Global.current_mode`。

新增/改場景節點與 signal 連線一律用 `godot-ai` MCP 工具
（`node_create`、`signal_manage`、`script_attach`），不要手改 `.tscn`，
規則見 `Ailley/CLAUDE.md`。

## 設計決策與踩過的坑

> [!warning] 這支腳本原本活在另一個分支，搬過來時两個依賴都斷了
> `main_menu.gd` 最早在 `feature/Sensing` 分支，放在 `scenes/main_menu.gd`
> （違反腳本一律進 `scripts/<領域>/` 的規則，這次搬過來順便修正到
> `scripts/ui/`）。它依賴的 `Global.gd` autoload 也只在那個分支存在，
> `main` 這邊完全沒有 —— 直接把場景切過來就會是
> `[ext_resource] referenced non-existent resource` 的 parse error。

> [!warning] 原本切的目標場景已經不存在
> 舊版是 `change_scene_to_file("res://scenes/village.tscn")`。`village.tscn`
> 在 `9a50ae0 refactor: rebuild the village on a shared Character base`
> 那次重構後就被拿掉了，現在唯一的主場景是 `main.tscn`。目標路徑照現況改掉，
> 不是原樣搬過來。

> [!warning] 根節點的 offset 把整個選單畫到螢幕外過
> `MainMenu` 根節點（`Control`）原本存的 `offset_top = -206`、`offset_bottom = -205`，
> 場景讀得進去、`current_scene.name` 也對，但三顆按鈕的 global rect 全部是負 y，
> 畫在 viewport（480x270）上緣以外，玩家什麼都看不到。用 `editor_screenshot(source="game")`
> 對實際遊戲畫面截圖才照出來——`viewport_2d` 截的是編輯器目前開著的分頁，不等於玩家看到的畫面。
> 修法是把 `offset_top`/`offset_bottom` 設回 `0`，讓根節點貼滿 viewport。

> [!note] autoload 要先註冊，腳本裡的 `Global` 才 resolve 得到
> 用 `script_create` 建 `main_menu.gd` 那當下，因為 `Global` autoload
> 還沒註冊，編輯器會報 `Identifier "Global" not declared`。
> 順序要是：先建 `Global.gd` → `autoload_manage(op="add")` 註冊 →
> 再建/存用到 `Global` 的腳本，或是建完之後重新存一次讓它 reload。
