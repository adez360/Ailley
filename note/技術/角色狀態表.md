# 角色狀態表

滑鼠左鍵點角色本體，彈出面板顯示姓名、年齡、飢餓、口渴、體力；
再點一次空白處或按 Esc 關閉。

## 資料

- `character_name`、`age`（`character.gd`）—— 身分欄位，純顯示用
- `Stats.SPEC` 的 `hunger` / `thirst` / `energy` —— 面板只挑這三項，
  不像主控台 `status` 指令那樣整份 `SPEC` 掃出來

`thirst` 是新加的數值，drift 4.0（比 `hunger` 的 3.0 略快），`place` 沿用
`restaurant`——地圖目前沒有獨立的水源地點，吃飯的地方一併能解渴。

「疲勞」與「體力」在這份狀態表裡是同一件事，不是兩個數值：欄位標籤用「體力」，
底層沿用原本的 `energy`（原標籤「精力」，改掉是因為「體力」更貼近飢餓／口渴
這組生存數值的語感）。沒有另外做一個會隨熬夜累積、只能靠睡覺清除的疲勞機制。

## 點擊偵測

用物理查詢而不是幫每個角色掛 `Area2D` 或開 `input_pickable`：

```gdscript
var params := PhysicsPointQueryParameters2D.new()
params.position = world_pos
params.collision_mask = 2   # character 層，見 [[Character 基底與 Agent]] 的分層表
get_viewport().world_2d.direct_space_state.intersect_point(params, 4)
```

跟 `nav_grid.gd`、`vision.gd` 是同一種手法——不必為了滑鼠多養一個節點，
也不用每幀查，點的當下才查一次。

> [!important] 螢幕座標要換成世界座標
> `StatusPanel` 是 `CanvasLayer`，沒有 `global_position` 可用，
> 滑鼠事件的 `event.position` 是螢幕座標。鏡頭跟著玩家跑，直接拿螢幕座標
> 當世界座標查物理空間，鏡頭一移動點擊位置就全部對不上。
> 做法是用 `get_viewport().canvas_transform.affine_inverse()` 換算。

## 場景結構

`main.tscn` 根節點下的 `StatusPanel`（`CanvasLayer`，掛 `status_panel.gd`）：

```
StatusPanel
  Panel（220x180，置中）
    VBox
      NameLabel / AgeLabel / HungerLabel / ThirstLabel / EnergyLabel / HintLabel
```

跟 `DebugConsole`、`ChatInput`、`HUD`、`PauseMenu` 同一層、同一種掛法——
獨立的 `CanvasLayer` 直接吊在場景根節點下。
