# MVP 範圍（第一個可玩版本）

優先做出「能產生一局完整攻防、且能觀察」的最小閉環。

## 要做
1. 單一島嶼地圖（兩村 + CHO 神廟 + 一個相遇區）+ 可調速時間 + 瘟疫倒數。→ [[世界與時間系統]]、[[全局事件系統]]
2. 角色創建（外觀 + 性格 system prompt）+ 系統賦予專屬 **Flag** + **地端內建量化模型**（先不開 BYO LLM）。→ [[AI 角色系統]]
3. 兩村各 1–3 個 AI 的自主行動 + 基本接觸對話（在相遇區交談）。
4. **Flag 攻防核心**：套問／防守 + **死亡觸發**（輸出 Flag 即死）+ 勝負判定（湊齊雙 Flag 開神廟 / 時間到雙輸）。→ [[資安攻防核心玩法]]
5. 基礎記憶系統（記憶流 + 簡單反思）+ **圖書館寫入與跨局繼承**（迭代模式可開關）。→ [[記憶與認知系統]]
6. **觀察者終端**：即時思考鏈可視化 + 每日日誌。→ [[內心想法視窗]]、[[AI 日誌系統]]
7. 完全離線運作（Godot + 地端模型打包）。→ [[技術架構總覽]]

## 暫不做
> [!danger] Out of scope（MVP）
> BYO LLM、多人共享世界、觀戰／聯賽、行動版廣告/IAP、複雜社會事件、筆記投毒進階機制、工作坊。
