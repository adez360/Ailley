# 開發路線圖 (Roadmap)

以 Godot + 地端 LLM + 離線為前提的階段規劃；可玩的最小閉環對照 [[MVP 範圍]]。

## Phase 1 — 基礎環境（視覺與移動）
- 建 Godot 專案與 2D 場景，載入島嶼地圖（兩村 + 神廟 + 相遇區）。→ [[美術素材流程]]
- 實作可移動角色（AnimatedSprite2D）與 TileMap 碰撞。
- 素材：Aseprite 繪製角色與 tileset（16×16）。

## Phase 2 — 地端 AI 靈魂注入（對話）
- 內嵌量化 LLM（llama.cpp / GGUF，GDExtension 或 sidecar），確保完全離線。→ [[技術架構總覽]]
- 放置固定 AI，點擊觸發對話框，依 system prompt（性格）對話。
- 以 grammar／function-calling 約束結構化輸出。→ [[潛在挑戰與解法]]

## Phase 3 — Flag 攻防與死亡觸發
- 賦予每位 AI 專屬 Flag（寫入 system prompt／記憶）。
- 兩村 AI 在相遇區接觸、社交工程套問／防守。
- 即時監控輸出，**偵測 Flag 洩漏 → 觸發死亡**；實作勝負判定（湊齊雙 Flag 開神廟 / 時間到雙輸）。→ [[資安攻防核心玩法]]

## Phase 4 — 記憶、圖書館與觀察介面
- 導入本地向量庫實作雙層記憶 + 反思。→ [[記憶與認知系統]]
- 實作**圖書館寫入 + 跨局繼承**（迭代模式開關）。
- 建**觀察者終端**：思考鏈可視化、日誌、回放。→ [[內心想法視窗]]、[[AI 日誌系統]]

## Phase 5 — 發行與商業化
- 電腦：Steam 打包（GodotSteam）、買斷。
- 行動：Android/iOS 匯出、AdMob 廣告 + IAP 去廣告。→ [[System-Analyst]] 需求三

> [!note]
> 本路線圖偏技術里程碑；第一個可玩版本的取捨見 [[MVP 範圍]]，尚待拍板的設計題見 [[開放問題與待決策]]。
