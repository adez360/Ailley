# 潛在挑戰與解法

## 1. API 成本過高
NPC 的每個決定都需要呼叫 LLM，成本消耗極快。
> [!success] 解法
> 在日常移動等低智力需求的決策上使用較小型模型（如 GPT-4o-mini）或傳統程式邏輯，僅在複雜對話時使用大型模型。

## 2. LLM 輸出格式不穩定
AI 可能無法完美回傳前端需要的 JSON 座標格式。
> [!success] 解法
> 嚴格利用 LLM 的 Function Calling (Tool Use) 功能，確保輸出結構化資料。

## 3. 記憶檢索不精準
隨時間推移，記憶累積過多導致 AI「忘記」重點。
> [!success] 解法
> 建立雙層記憶系統（短期 Working Memory + 長期 Vector Retrieval），並定期讓 AI 對記憶進行「總結與反思」(Reflection)。詳見 [[記憶與認知系統]]。
