# 技術架構總覽

> [!info] 來源
> 出自 `ideas/pre-plan.md`，偏「Web + Phaser + LLM」的實作路線。

## 前端 (Frontend)
- **遊戲核心**：Phaser.js（2D 像素渲染、角色移動、動畫與地圖碰撞）
- **地圖編輯**：Tiled（匯出 JSON 地圖檔供 Phaser 讀取）
- **美術素材**：Aseprite（像素畫 + 逐格動畫；Phaser 原生支援其匯出格式）；**格點定案 16×16** → [[美術素材流程]]
- **UI 框架**：React 或 Vue.js（對話框、NPC 狀態面板等 UI 介面）

## 後端 (Backend)
- **伺服器**：Python (FastAPI) 或 Node.js
- **即時通訊**：WebSockets（確保 NPC 移動與對話能即時推播給前端）

## AI 與資料層 (AI & Data)
- **大腦 (LLM)**：OpenAI API (GPT-4o-mini / GPT-4o) / Claude 3.5 Sonnet
	- 對應玩家可選的 [[AI 角色系統|BYO Token／雲端／地端]] 三種大腦來源
- **記憶與檢索**：向量資料庫（Pinecone / ChromaDB / PostgreSQL + pgvector）→ [[記憶與認知系統]]
- **世界狀態儲存**：PostgreSQL（物件座標、時間、NPC 基礎設定檔）→ [[世界與時間系統]]
