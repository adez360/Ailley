# 美術素材流程（Aseprite → Tiled → Phaser）

> [!success] 結論：非常可行
> Aseprite 是像素畫 + 逐格動畫的業界標準工具，和本專案的 [[技術架構總覽|Phaser + Tiled + 2D 像素風]] 完美契合。Phaser 3 甚至**原生支援 Aseprite 的匯出格式**，是最省事的選擇之一。

## 兩條產線

### A. 角色 / 物件動畫
1. 在 Aseprite 畫角色，用 **Tags** 標記各動作（`idle`、`walk-down`、`walk-up`、`work`…）。
2. 匯出 **Sprite Sheet**：PNG（圖）+ JSON（frame 座標與 tag 資料）。
3. Phaser 載入：
   - `this.load.aseprite(key, 'char.png', 'char.json')`
   - `this.anims.createFromAseprite(key)` → **Aseprite 的 tags 會自動變成 Phaser 動畫**，不用手刻 frame 範圍。
4. 對應 [[開發路線圖|Phase 1]]（可移動角色）與 Phase 3（走路動畫）。

### B. 地圖 tileset
1. 在 Aseprite 畫 **tileset**（統一格點，見下），匯出成一張 PNG。
2. 匯入 **Tiled**，設定 tile 尺寸，拼出地圖（住宅、市集、農田、礦山…見 [[世界與時間系統]]）。
3. Tiled 匯出 JSON → Phaser `this.load.tilemapTiledJSON()` + `this.make.tilemap()` 讀取，碰撞層對應 [[開發路線圖|Phase 1]] 的碰撞偵測。

## 開工前要先定的規格
> [!check] 已定案：格點大小 = 16×16
> 全專案角色與 tile 一律以 **16×16 px** 為基準（星露谷同規格，資訊密度與工作量平衡好）。此為專案定案，不再改動。

- **格點大小（✅ 已定 16×16）**：所有 tile、角色以 16×16 為基準；較大的物件用 16 的倍數（直立物件 16×32、大件 32×32…），確保能對齊網格。
- **調色盤 (Palette)**：在 Aseprite 建一個共用 palette，所有素材沿用，畫面才統一。可沿用 [[參考素材]] 的概念圖定調。
- **命名規範**：`char_villager_idle`、`tile_farm_soil`… 方便載入與管理。

## 常見坑
- **Tile 接縫滲色 (bleeding)**：地圖縮放時相鄰 tile 邊緣會透出雜線。解法：匯出時對 tileset 做 **extrude**（邊緣外擴 1px），或 Tiled 內設 margin/spacing。
- **像素銳利度**：Phaser 設定 `pixelArt: true`（等同關閉抗鋸齒 + `roundPixels`），否則像素會糊掉。
- **縮放**：以整數倍放大（1x/2x/3x）維持 pixel-perfect。
