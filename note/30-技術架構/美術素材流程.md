# 美術素材流程（Aseprite → Godot）

> [!success] 結論：可行
> Aseprite 是像素畫 + 逐格動畫的業界標準工具，與本專案的 [[技術架構總覽|Godot + 2D 像素風]] 契合。Godot 可直接匯入 Aseprite 匯出的 Sprite Sheet，社群另有 Aseprite Wizard 等外掛可自動生成 SpriteFrames／AnimatedSprite。

## 兩條產線

### A. 角色 / 物件動畫
1. 在 Aseprite 畫角色，用 **Tags** 標記各動作（`idle`、`walk-down`、`walk-up`、`talk`…）。
2. 匯出 **Sprite Sheet**：PNG（圖）+ JSON（frame 座標與 tag 資料）。
3. Godot 匯入：用 `AnimatedSprite2D` + `SpriteFrames`，或以 Aseprite Wizard 外掛依 tags 自動生成動畫。
4. 對應 [[開發路線圖|Phase 1]]（可移動角色）與後續走路／對話動畫。

### B. 地圖 tileset
1. 在 Aseprite 畫 **tileset**（統一格點，見下），匯出成一張 PNG。
2. 用 Godot 內建 **TileSet / TileMap** 編輯器拼島嶼地圖（兩村、神廟、相遇區…見 [[世界與時間系統]]）；也可從 Tiled 匯入（社群外掛）。
3. 設定碰撞層，對應 Phase 1 的碰撞偵測。

## 開工前要先定的規格
> [!check] 已定案：格點大小 = 16×16
> 全專案角色與 tile 一律以 **16×16 px** 為基準（資訊密度與工作量平衡好）。較大物件用 16 的倍數（16×32、32×32…）。

- **調色盤 (Palette)**：Aseprite 建共用 palette，所有素材沿用。可沿用 [[參考素材]] 概念圖定調（兩村紅／藍主色）。
- **命名規範**：`char_tammy_idle`、`tile_shrine_floor`… 方便匯入與管理。

## 常見坑
- **Tile 接縫滲色 (bleeding)**：匯出時對 tileset 做 **extrude**（邊緣外擴 1px），或在 TileSet 設 margin/separation。
- **像素銳利度**：Godot 專案的紋理過濾設為 **Nearest**（關閉抗鋸齒），否則像素會糊掉。
- **縮放**：以整數倍放大維持 pixel-perfect。
