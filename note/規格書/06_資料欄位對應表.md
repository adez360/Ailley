## 3. 已廢止欄位

以下欄位不再存在。若在舊程式碼或舊存檔中看到，一律忽略。

| 廢止欄位 | 原用途 | 現在怎麼做 |
| --- | --- | --- |
| `values.*`（8 項） | 價值觀權重配點 | 由 `character` 自由文本表達 |
| `state.mental.stress` | 壓力值 | 由 `emotion` 承載 |
| `state.mental.loneliness` | 孤獨值 | 由事實句表達（見《01-3》§3） |
| `state.mental.satisfaction` | 滿足值 | 由 `today_plan` / `current_goal` 承載 |
| `secrets[]` | 秘密陣列 | 改為單一 `words_to_creator` |
| `exposure_stress` | 秘密曝光壓力 | 無此機制 |
| `creed` | 人生信條 | 由行為準則文字取代 |
| `backstory` | 出身背景 | 併入 `character` |
| `appearance`（string 型） | 外表描述 | 改為陣列型 `appearance[]` |
| `skill_*` | 技能熟練度 | 成功率改由人格＋生理決定 |

## 4. 命名約定

| # | 規則 |
| --- | --- |
| 1 | 欄位一律 `snake_case`，不用駝峰 |
| 2 | HEXACO 六維一律加 `hex_` 前綴（避免與 `personality.honesty` 混淆） |
| 3 | ID 格式：`npc_001` / `loc_well` / `evt_1043` / `sec_001` |
| 4 | 布林欄位用 `is_` 開頭（`is_exposed`、`is_alive`） |
| 5 | 時間欄位用 `_at` 結尾（`created_at`、`generated_at`） |
| 6 | 「甘道夫石」正式名稱統一為「天神之石 `obj_divine_stone`」 |
