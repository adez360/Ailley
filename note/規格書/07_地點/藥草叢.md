# 藥草叢（`loc_herb_field`）

**用途**：採集藥草
**容量上限**：4

> [!note] MVP 範圍（2026-08-24 拍板拉進這學期專題發表，見《17》「正式工作與經濟系統」）
> 採集拉進 MVP，沿用「單次判定」既有動作模式（跟 `buy`／`eat` 同一種寫法），是這批
> 新增動作裡工程量最低的一項，尚未實作。

## 地點結構

```json
{
  "location_id": "loc_herb_field",
  "name": "藥草叢",
  "capacity": 4,
  "danger": 0,
  "resources": ["herb"],
  "available_actions": ["gather", "move_to", "rest"],
  "regen": { "herb": 36 }
}
```

`resources`／`regen` 已隨《08》§7（`herb` 再生 36 tick）定案；`danger` 目前定 0（跟藥草鋪等
安全地點同一套，跟《07_地點與行動》採「非森林類地點預設安全」的既有慣例一致，未另外
拍板過危險度數值——如果之後想讓藥草叢也有環境風險，需要另外拍板具體數字，不是延用這裡的
0）。欄位定義見《[[07_地點與行動]]》地點資料結構。

## 可用行動

- `gather` —— 採集藥草（見《[[07_地點與行動]]》§2-3）
- 通用行動（`move` / `rest` / `idle` / `talk`）一律可用，見《[[07_地點與行動]]》§5
