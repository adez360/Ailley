# 長椅（`loc_bench`）

**用途**：休息、兩人對話
**容量上限**：2【推測】

> [!note] 不在這學期 MVP 範圍（見《17》「未來願景」）
> `rest`／`talk` 兩個行動本身在其他 MVP 地點都能做，長椅只是提供一個場景意義上的
> 專屬休憩點，不是解鎖新機制，`loc_bench` 目前程式碼裡沒有任何實作。

## 地點結構

`danger` / `resources` / `regen` 未定，欄位定義見《[[07_地點與行動]]》地點資料結構。

## 可用行動

- `rest` —— 原地發呆，小幅回復體力（見《[[07_地點與行動]]》§2-4）
- `talk` —— 兩人對話，見《[[11_人際互動與社交行為]]》
- 通用行動（`move` / `rest` / `idle` / `talk`）一律可用，見《[[07_地點與行動]]》§5
