# 長椅（`loc_bench`）

**用途**：休息、兩人對話
**容量上限**：2【推測】

> [!note] 不在這學期 MVP 範圍（見《17》「未來願景」）
> `talk` 在其他 MVP 地點都能做，長椅只是提供一個場景意義上的專屬休憩點，
> 不是解鎖新機制，`loc_bench` 目前程式碼裡沒有任何實作。

## 地點結構

`danger` / `resources` / `regen` 未定，欄位定義見《[[07_地點與行動]]》地點資料結構。

## 可用行動（本地點完整版才有——`loc_bench` MVP 期間不存在，見上方 callout；
`talk` 本身不是新行動，MVP 期間在其他既有地點一樣能用，差的只是這個
專屬場景）

- `rest`／`nap` —— 由引擎內部分級，非 LLM 可選（見《[[07_地點與行動]]》§5）
- `talk` —— 兩人對話，見《[[11_人際互動與社交行為]]》
- 通用行動（`move` / `idle` / `talk`）一律可用，見《[[07_地點與行動]]》§5
