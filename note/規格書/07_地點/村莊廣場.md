# 村莊廣場（`loc_square`）

**用途**：村民聚集、閒聊社交——公共空間，不綁定特定行動
**容量上限**：10【推測】

跟[[涼亭]]的差別：涼亭是圈著樹籬、南側留缺口的院子（小型半封閉結構），
村莊廣場是村莊中央的開放空間，用途上都涵蓋「聚集」，但兩者是各自獨立的
地點，不合併（2026-08-23 拍板）。

## 地點結構

`danger: 0` / `resources: []` / `regen: {}`——比照涼亭，安全的公共社交地點，
沒有可採集的資源，欄位定義見《[[07_地點與行動]]》地點資料結構。

座標尚未定案，需要補進《[[村莊地圖]]》。

## 可用行動

通用行動（`move` / `rest` / `idle` / `talk`）一律可用，見《[[07_地點與行動]]》§5。
