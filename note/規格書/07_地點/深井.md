# 深井（`loc_well`）

**用途**：取水
**容量上限**：2【推測】

> [!note] 不在這學期 MVP 範圍，但用途已定義清楚（見《17》「未來願景」）
> `wash`（洗澡）／`drink`（飲水）就是深井的用途，這點不需要再重新設計。這次先不建
> 是評估 UI 工作份量後的選擇——`hygiene` 改成工作驅動（打獵／採集／表演會弄髒角色，
> 見《99》P-65）之後，深井變成 MVP 期間唯一的清潔手段，但目前決定先不做，角色會停在
> 「骯髒」狀態標籤，不影響任何成功率或機制，是可接受的已知限制。`loc_well` 目前程式碼
> 裡沒有任何實作。

## 地點結構

`danger` / `resources` / `regen` 未定，欄位定義見《[[07_地點與行動]]》地點資料結構。

## 可用行動

- `wash`（完整版才有——本地點 MVP 期間不存在，見上方 callout） —— 提升 `hygiene`，
  完整版規劃 `loc_lake` 或 `loc_well` 兩處可用（見《[[07_地點與行動]]》§2-4）
- `drink` —— 任意地點皆可，此處天然有水源
- 通用行動（`move` / `rest` / `idle` / `talk`）一律可用，見《[[07_地點與行動]]》§5
