# 涼亭（`loc_pavilion`）

**用途**：休息、演奏、聚集
**容量上限**：6

## 地點結構

`danger: 0` / `resources: []` / `regen: {}`（2026-08-16 拍板）——涼亭是安全的休憩地點，
沒有可採集的資源，欄位定義見《[[07_地點與行動]]》地點資料結構。

`desc: "5 個院子裡最北的一個，樹籬圍出的空間，缺口朝南對著其他地點。"`（依《[[村莊地圖]]》：
`pavilion` 院子 y:-9..-5，是 5 個院子中最北的一個，但地圖本身範圍到 y:-11，涼亭不是地圖
邊界；跟其餘 4 個地點一樣圈著樹籬留缺口，不是無遮蔽的空地，南側缺口 `(4,-5)` 面向其餘地點）

## 可用行動

- `rest` —— 原地發呆，小幅回復體力（見《[[07_地點與行動]]》§2-4）
- `perform` —— 演奏。**現況（2026-08-27 更新）**：MVP 已改「隨地表演」，不限定本地點，見《99》P-62 #5；觀眾人數不影響成功率，只當環境事實讓 AI 自己判斷，見《99》P-62 #6、《[[11_人際互動與社交行為]]》。**尚未接上白名單**：`perform` 還不在 `Ailley/scripts/ai/ai_schema.gd` 的 `IMPLEMENTED_ACTIONS`，LLM 目前選不到，見《[[01-2_行為判定規則]]》§3 註
- 通用行動（`move` / `rest` / `idle` / `talk`）一律可用，見《[[07_地點與行動]]》§5
