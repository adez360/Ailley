# 涼亭（`loc_pavilion`）

**用途**：休息、演奏、聚集
**容量上限**：6【推測】

## 地點結構

`danger: 0` / `resources: []` / `regen: {}`（2026-08-16 拍板）——涼亭是安全的休憩地點，
沒有可採集的資源，欄位定義見《[[07_地點與行動]]》地點資料結構。

`desc: "地圖最北端，地勢開闊、四面無遮蔽，風聲比其他地方都清楚。"`（依《[[村莊地圖]]》：
`pavilion` 院子 y:-9..-5，是 5 個院子中最北的一個，南側缺口 `(4,-5)` 面向其餘地點）

## 可用行動

- `rest` —— 原地發呆，小幅回復體力（見《[[07_地點與行動]]》§2-4）
- `perform` —— 演奏，觀眾人數影響成功率，見《[[11_人際互動與社交行為]]》
- 通用行動（`move` / `rest` / `idle` / `talk`）一律可用，見《[[07_地點與行動]]》§5
