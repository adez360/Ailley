# 洗心革面所（`loc_reform`）

**用途**：舉報累積 3 次後被拘留
**容量上限**：3

## 地點結構

`danger` / `resources` / `regen` 未定，欄位定義見《[[07_地點與行動]]》地點資料結構。

## 可用行動

通用行動（`move` / `idle` / `talk`）一律可用，見《[[07_地點與行動]]》§5。

## 交叉引用

- `report` 舉報行動見《[[11_人際互動與社交行為]]》，累積 3 次觸發拘留

## 待確認

見《[[99_待規劃項目清單]]》P-17。
