# 森林（`loc_forest`）

**用途**：打獵（含環境危險度）
**容量上限**：4

## 地點結構

```json
{
  "location_id": "loc_forest",
  "name": "森林",
  "desc": "樹影很密，聽得到不知名的動物聲。",
  "capacity": 4,
  "danger": 20,
  "resources": ["small_game", "large_game"],
  "available_actions": ["hunt_small", "hunt_large", "move", "rest"],
  "regen": { "small_game": 36, "large_game": 144 }
}
```

欄位定義見《[[07_地點與行動]]》地點資料結構。此為目前唯一附完整 JSON 範例的地點；家／涼亭／藥草鋪／餐酒館／村莊廣場已各自在自己的筆記裡定案 `danger: 0`／`resources: []`／`regen: {}`（安全地點，見各自筆記），不是還沒填——真正還待填寫這三個欄位的是其餘尚未拍板容量以外細節的地點。

## 可用行動

- `hunt_small` / `hunt_large` —— 打獵（見《[[07_地點與行動]]》§2-3、《[[01-2_行為判定規則]]》成功率）
- 通用行動（`move` / `rest` / `idle` / `talk`）一律可用，見《[[07_地點與行動]]》§5
