# 餐酒館（`loc_tavern`）

**用途**：飲食、喝酒、社交
**容量上限**：8

## 地點結構

`danger: 0` / `resources: []` / `regen: {}`（2026-08-16 拍板）——餐酒館是安全的商業地點，
沒有可採集的資源，欄位定義見《[[07_地點與行動]]》地點資料結構。

`desc: "人聲與碗盤碰撞聲不斷，西邊隔著一片空地能看到天神之石。"`（依《[[村莊地圖]]》：
`tavern` 院子西側缺口 `(8,3)` 與 `god_stone` 院子同一緯度、隔著沒種樹籬的空地相望。
`buy` 互動綁在錨點 `(170, 50)` 本身，不是場景裡的實體物件，見《[[販賣機]]》）

## 可用行動

- `eat` / `drink` —— 任意地點皆可，需持有食物／飲品（見《[[07_地點與行動]]》§2-2）
- `buy` —— 見《[[07_地點與行動]]》§2-2，MVP 沿用已實作的商店機制（`技術/販賣機.md`），上架品項見《[[08_物品與經濟]]》§0（`ale`／`cooked_meat`／`water` 三樣）；不做 `sell`，MVP 兩間店只做販售不做收購（見《[[08_物品與經濟]]》）
- 通用行動（`move` / `idle` / `talk`）一律可用，見《[[07_地點與行動]]》§5
- 社交類行動（`talk` / `persuade` / `give` / `perform` 等）見《[[11_人際互動與社交行為]]》
