# 家（`loc_home`）

**用途**：睡眠（回復量最大）、家中儲存
**容量上限**：1【推測】

**每個角色各自一間**：`loc_home` 不是單一地點，是每個角色的 `home_location_id`（《01》§1-1）
指到的其中一筆。AI 決策時仍只看到抽象的 `loc_home`（跟其他地點一樣用 `location_id`），
引擎收到目標為 `loc_home` 的動作時，依發起角色的 `home_location_id` 解析成實際座標——
角色之間互不相通，A 的家不是 B 的家。

**地圖上放固定幾間房子，建角時系統自動分配**（2026-08-16）：玩家不用選。

**間數與分配方式**（2026-08-20 拍板，見 issue #370）：房子間數跟著房主建立世界時設定的
人數上限走，不是寫死的數字——MVP／Phase 2 階段人數上限剛好是 5 個 NPC，地圖上就手動擺
5 間，不會有「房子不夠用」的情境（人數上限已經先卡住角色數上限）。分配方式採循環
（round-robin）：依建角順序依序指派到下一間空房。

地圖動態擴張（人數上限中途調高）與同居功能（多角色共用一間房子）不在這次拍板範圍內，
留到 Phase 3/4，見《[[99_待規劃項目清單]]》P-53。

## 地點結構

`danger: 0` / `resources: []` / `regen: {}`（2026-08-16 拍板）——家沒有環境危險，也沒有可採集
的資源，欄位定義見《[[07_地點與行動]]》地點資料結構。

`desc: "籬笆圍出的小院子，南邊出口正對著藥草鋪的門，走幾步就到。"`（依《[[村莊地圖]]》實際佈局：
`home` 院子南側缺口 `(-8,-2)` 與 `herb_shop` 院子北側缺口 `(-7,3)` 幾乎同一條垂直線上，
兩院子入口互相正對）

## 可用行動

- `sleep` —— 自己家回復量最大（見《[[07_地點與行動]]》§2-4）
- 通用行動（`move` / `rest` / `idle` / `talk`）一律可用，見《[[07_地點與行動]]》§5
