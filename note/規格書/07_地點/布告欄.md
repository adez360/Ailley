# 布告欄（`loc_board`）

**用途**：同一塊板身兼兩用途（2026-08-23 拍板，不拆成兩個地點）——
系統自動記錄較大或吸睛的事件（見《[[10_模式連線與世界設定規格書]]》§9 B35），
也開放玩家張貼留言（兩村各一）
**容量上限**：4【推測】

## 地點結構

`danger` / `resources` / `regen` 未定，欄位定義見《[[07_地點與行動]]》地點資料結構。

## 可用行動

通用行動（`move` / `rest` / `idle` / `talk`）一律可用，見《[[07_地點與行動]]》§5。玩家張貼留言的功能（張貼、閱讀）尚未定義對應 `action`，待確認；系統自動記事（B35）不是玩家觸發的 `action`，走事件記錄管線。

## 待確認

見《[[99_待規劃項目清單]]》P-17。
