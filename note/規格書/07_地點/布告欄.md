# 布告欄（`loc_board`）

**用途**：留言板（兩村各一）
**容量上限**：4【推測】

## 地點結構

`danger` / `resources` / `regen` 未定，欄位定義見《[[07_地點與行動]]》地點資料結構。

## 可用行動

通用行動（`move` / `rest` / `idle` / `talk`）一律可用，見《[[07_地點與行動]]》§5。留言板本身的功能（張貼、閱讀）尚未定義對應 `action`，待確認。

## 待確認
