## 1. 物品結構

```json
{
  "item_id": "herb",
  "count": 4,
  "decay": 22,
  "durability": 100
}
```

| 欄位 | 型別 | 範圍 | 說明 |
| --- | --- | --- | --- |
| `item_id` | string | — | 物品代號 |
| `count` | int | ≥ 0 | 數量 |
| `decay` | int | 0–100 | 腐壞值，**100 = 完全腐壞** |
| `durability` | int | 0–100 | 耐久值，**0 = 損毀** |

### 兩個數值的差別

|  | `decay` 腐壞 | `durability` 耐久 |
| --- | --- | --- |
| 方向 | 越高越糟 | 越低越糟 |
| 隨時間變化 | ✔ 自動上升 | ✘ 只在使用時下降 |
| 適用 | 食物、飲品、獵物、水產、採集品 | 隨身用品 |
| 歸零／滿值時 | 不可食用，`eat` 判定失敗 | 損毀，自動移除 |

| 分類 | 英文 | 使用 `decay` | 使用 `durability` | 說明 |

## 4. 容量與儲存

| 位置 | 欄位 | 上限 | 說明 |
| --- | --- | --- | --- |
| 隨身 | `economy.inventory` | **8 格** | 一格 = 一種物品，可堆疊 |
| 家中 | `economy.home_storage` | **20 格** | 僅在 `loc_home` 可存取 |

### 堆疊規則　【推測待確認】

| # | 規則 |
| --- | --- |
| 1 | 同 `item_id` 且 `decay` 差距 ≤ 10 時可堆疊，取較差的 `decay` |
| 2 | `carry` 類（有 `durability`）**不可堆疊**，一件佔一格 |
| 3 | 格數滿時無法取得新物品，判定失敗，`reason` 寫「你身上已經沒有位置了」 |

## 5. 經濟循環

```
        ┌─────────────────────────────────────┐
        │              收入                    │
        │  打獵 → 獵物 → 賣給商鋪              │
        │  採集 → 藥草 → 賣給藥草鋪            │
        │  捕魚 → 魚   → 賣給商鋪              │
        │  演奏 → 路人或玩家給錢                │
        └──────────────┬──────────────────────┘
                       ▼
                  ┌─────────┐
                  │  money  │  預設 300
                  └────┬────┘
                       ▼
        ┌─────────────────────────────────────┐
        │              支出                    │
        │  餐酒館 → 食物、酒                   │
        │  藥草鋪 → 藥品                       │
        │  服裝鋪 → 衣物                       │
        │  工具   → 刀、樂器                   │
        └─────────────────────────────────────┘
```

### 商鋪對應

| 地點 | 收購 | 販售 |
| --- | --- | --- |
| `loc_herb_shop` | 藥草、野果 | 藥品、藥草湯 |
| `loc_clothing_shop` | 衣物 | 衣物 |
| `loc_tavern` | 獵物、魚 | 食物、飲品 |

### 交易規則　【推測待確認】

| # | 規則 |
| --- | --- |
| 1 | 商鋪收購價 = 售價 × 0.5 |
| 2 | `decay` 越高收購價越低：實際收購價 = 基準 × (100 − decay) / 100 |
| 3 | `reputation < -50` 時商店拒絕交易 |
| 4 | 商鋪庫存與現金為無限【推測待確認】，不做商鋪經營模擬 |

## 6. 腐壞與耐久

### 6-1 腐壞

```
每 tick：decay += 該物品的腐壞速率

decay ≥ 100 → 標記為腐壞
```

| `decay` | 狀態 | 效果 |
| --- | --- | --- |
| 0–39 | 新鮮 | 正常 |
| 40–79 | 不新鮮 | 食用時 `health` -3【推測待確認】 |
| 80–99 | 快壞了 | 食用時 `health` -10【推測待確認】 |
| 100 | 腐壞 | 不可食用，`eat` 判定失敗 |

> `home_storage` 的腐壞速率減半【推測待確認】——家裡比背包涼快。
> 

### 6-2 耐久

```
每次使用：durability -= 該物品的耐久消耗

durability ≤ 0 → 損毀，自動從庫存移除
```

損毀時寫入 `last_action_result`：「你的刀在使用中斷掉了。」
