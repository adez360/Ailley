# 01-1_人格生成規格書

# 01-1｜人格生成規格書

**閱讀對象**：前端組・後端組
**文件性質**：建角流程規格。玩家怎麼捏角色、六維怎麼變成十項引擎參數、System Prompt 怎麼組。
**前置閱讀**：《00 設計原則與架構》

---

## 1. 資料流

完整流程圖見《00 設計原則與架構》§6「建角資料流」，兩邊講的是同一件事，不重複畫。

**關鍵**：轉換**只在建角時跑一次**。之後睡覺反思的 ±3 直接改 `personality` 的 10 項，**不回推滑桿**。滑桿值只保留作建角紀錄與面板顯示。

## 2. 前端輸入規格

### 2-1 六維滑桿

| 中文 | 英文欄位 | 0% 端 | 100% 端 | 預設 |
| --- | --- | --- | --- | --- |
| 誠實謙遜 | `hex_honesty` | 狡猾自私 | 真誠無私 | 50 |
| 情緒起伏 | `hex_emotionality` | 冷酷無情 | 敏感多愁 | 50 |
| 外向性 | `hex_extraversion` | 孤僻自閉 | 社交狂熱 | 50 |
| 友善性 | `hex_agreeableness` | 充滿敵意 | 溫和包容 | 50 |
| 嚴謹性 | `hex_conscientiousness` | 散漫衝動 | 嚴密自律 | 50 |
| 開放性 | `hex_openness` | 傳統保守 | 獵奇創新 | 50 |
- 型別 `int`，範圍 0–100，滑桿最小刻度 5
- **一律加 `hex_` 前綴**：HEXACO 的「誠實謙遜」與引擎參數 `honesty`（誠實度）不是同一個東西，不加前綴一定會有人接錯
- 「情緒起伏」不可寫成「情緒穩定度」，方向會反（低 = 冷靜，高 = 敏感）

### 2-2 自由文本 `character`

| 欄位 | 型別 | 必填 | 限制 |
| --- | --- | --- | --- |
| `character` | string | ✗ | 上限 **250 字** |

面板文案：

```
標題：這個角色是什麼樣的人？（選填）

placeholder：
崩塌前是機房維修員，獨自活過三次斷電。
說話很短，不耐煩時會發出鼻音。
最在乎自己的東西不被別人碰。
```

- placeholder 三句分別示範背景、口癖、在意什麼。玩家會自然混著寫，**不需要另外解釋規則，也不要拆成多個框**
- 面板下方小字：「寫外表、口癖、過去經歷、他最在乎什麼都可以。不要寫能力或數值。」
- 附一顆「**隨機範例**」按鈕，從 50 個 NPC 模板庫抽一段填入

### 2-3 存檔驗證規則

定義：**極端項** = 該滑桿 ≤ 25 或 ≥ 75。

| 情況 | 極端項數量要求 |
| --- | --- |
| `character` 有填 | **2 ≤ n ≤ 4** |
| `character` 留空 | **3 ≤ n ≤ 4** |
- **下限**：防止生出沒有人設的空殼村民（滑桿全 50 ＋ 文本空 = prompt 只剩一句「你正在扮演一個遊戲角色」）
- **上限 4**：六維全推極端會產生互相打架的人設，且 prompt 過長
- 未達標時**擋下存檔**，提示「再把 N 個滑桿推向兩端，這個角色才有個性」
- **50 個 NPC 模板的隨機產生器套用同一條驗證式**，否則隨機村民會全部趨中
- 面板需即時顯示目前極端項計數

## 3. 後端轉換：6 維 → 10 引擎參數

| 引擎參數 | 中文 | 計算式 |
| --- | --- | --- |
| `diligence` | 勤勉 | `hex_conscientiousness` |
| `courage` | 膽識 | `(100 − hex_emotionality) × 0.5 + hex_openness × 0.3 + hex_extraversion × 0.2` |
| `sociability` | 社交 | `hex_extraversion` |
| `morality` | 道德 | `hex_honesty × 0.7 + hex_agreeableness × 0.3` |
| `stability` | 情緒穩定 | `100 − hex_emotionality` |
| `romanticism` | 浪漫藝術 | `hex_openness × 0.6 + hex_emotionality × 0.4` |
| `curiosity` | 好奇心 | `hex_openness` |
| `grudge` | 記仇度 | `(100 − hex_agreeableness) × 0.6 + hex_emotionality × 0.4` |
| `greed` | 貪婪 | `(100 − hex_honesty) × 0.7 + (100 − hex_conscientiousness) × 0.3` |
| `honesty` | 誠實度 | `hex_honesty` |
- 結果 `round()` 取整，夾制 `0 ~ 100`
- **不要省略這層**：`courage` 支撐打獵／偷竊／攻擊三種行為的成功率，`romanticism` 支撐演奏，`grudge` 是記憶衰減率的參數——這三項在 HEXACO 六維裡沒有直接對應欄位，砍掉這層會讓《01-2》行為判定表算不出來

> [!note] `greed`／`courage` 公式已解開綁死（2026-08-16，見《99》P-12）
> 舊式 `greed = 100 − hex_honesty`、`stability`／`courage` 同吃 `100 − hex_emotionality`，
> 兩組都恆為互補（相加=100），做不出「貪婪但誠實」「情緒穩定但膽小」這類角色。
> 改成上表後 `stability` 維持原式（純粹的情緒穩定度，仍只吃 `hex_emotionality`），
> `courage` 額外混入 `hex_openness`／`hex_extraversion`、`greed` 額外混入 `hex_conscientiousness`，
> 兩組不再恆互補。50 個官方模板跟玩家角色一樣走這套 6→10 轉換，不跳過、不手寫最終值。

```
func hexaco_to_personality(h: Dictionary) -> Dictionary:
    var c := func(v: float) -> int: return clampi(roundi(v), 0, 100)
    return {
        "diligence":    c.call(h.conscientiousness),
        "courage":      c.call((100 - h.emotionality) * 0.5 + h.openness * 0.3 + h.extraversion * 0.2),
        "sociability":  c.call(h.extraversion),
        "morality":     c.call(h.honesty * 0.7 + h.agreeableness * 0.3),
        "stability":    c.call(100 - h.emotionality),
        "romanticism":  c.call(h.openness * 0.6 + h.emotionality * 0.4),
        "curiosity":    c.call(h.openness),
        "grudge":       c.call((100 - h.agreeableness) * 0.6 + h.emotionality * 0.4),
        "greed":        c.call((100 - h.honesty) * 0.7 + (100 - h.conscientiousness) * 0.3),
        "honesty":      c.call(h.honesty),
    }
```

## 4. 極端值映射表

只有 ≤ 25 或 ≥ 75 的維度會產生文字。**26–74 一律不輸出任何字**——不是輸出「普通」，是整條略過。

中間值不寫進 prompt，就是留給 AI 的自主空間。

### 傾向式語氣（2026-08-16 拍板）

文案只給偏好，不規定行為——舊版用「極度」「毫不猶豫」「從不」這類絕對句，等於比數值本身還更強力地規定 LLM 怎麼做，跟「給 AI 自主決策最大空間」的方向相反。改成傾向式後，LLM 自己決定這次要不要例外，偶爾破例才像人。

每一端準備 **3 種語氣變體**，建角時隨機抽一條，避免 50 個 NPC 模板讀起來千篇一律。

| 維度 | ≤ 25（3 選 1） | ≥ 75（3 選 1） |
| --- | --- | --- |
| `hex_honesty` | ①你把自己的利益放得很前面，說謊對你沒什麼心理負擔。<br>②需要的時候，你不介意繞過誠實這條線來達成目的。<br>③你認為適度的算計是生存的一部分，老實不代表要放棄機會。 | ①你很看重誠信，能不騙人就不騙，即使會吃虧。<br>②你不喜歡佔別人便宜，事情攤開來講反而讓你自在。<br>③說謊會讓你渾身不對勁，你寧可承認失敗也不編故事。 |
| `hex_emotionality` | ①面對衝擊性的事，你的反應通常比旁人平淡許多。<br>②你不太容易被情緒牽著走，遇到壞消息也能很快恢復理智。<br>③別人覺得該難過的場合，你常常只是覺得事情就是這樣。 | ①小事也容易在你心裡留下很深的痕跡，情緒起伏比一般人明顯。<br>②你很容易被氣氛感染，開心或難過都藏不太住。<br>③遇到不順心的事，你需要花不少時間才能平復下來。 |
| `hex_extraversion` | ①你不喜歡社交，跟人講話容易疲乏，通常不會主動延續話題。<br>②一個人待著對你來說比較自在，人多的場合會讓你想找藉口離開。<br>③你話不多，除非對方先開口，否則你很少主動搭話。 | ①你喜歡熱鬧，跟人聊天會讓你充滿活力，常常捨不得結束對話。<br>②安靜的場合會讓你不自在，你習慣主動找話題、帶動氣氛。<br>③你很享受成為話題中心，容易在聊天裡多講一點自己的事。 |
| `hex_agreeableness` | ①你講話直，不太顧慮會不會傷到人，容易讓人覺得帶刺。<br>②別人得寸進尺時，你不會忍讓，反而會直接頂回去。<br>③你對陌生人習慣先抱持懷疑，不輕易釋出善意。 | ①你不太會拒絕別人，即使自己已經有點勉強。<br>②你傾向先體諒對方的立場，很少直接跟人起衝突。<br>③讓步對你來說沒什麼大不了，維持和氣比爭對錯重要。 |
| `hex_conscientiousness` | ①計畫對你來說比較像參考，臨時想到什麼就容易改變主意。<br>②你做事憑當下的感覺，不太習慣按部就班。<br>③截止日期這種東西常常抓不準，你更相信船到橋頭自然直。 | ①你做事習慣照計畫走，臨時被打亂步調會讓你不太舒服。<br>②細節沒處理好會讓你耿耿於懷，你寧可多花時間也要做對。<br>③你對自己要求高，交出去的事情很少是隨便應付的。 |
| `hex_openness` | ①你對沒試過的東西通常抱持懷疑，習慣用熟悉的方式做事。<br>②太新奇的想法會讓你不太放心，你更信任經過驗證的做法。<br>③改變既有習慣對你來說不是件輕鬆的事。 | ①沒見過的東西會讓你忍不住想湊近看看，就算有點風險。<br>②一成不變的日子會讓你覺得無聊，你偏好嘗試新做法。<br>③別人覺得奇怪的點子，你反而容易躍躍欲試。 |

**實作**：存成 `res://data/hexaco_traits.json`，`low`／`high` 各存一個陣列，建角時從陣列隨機抽一條：

```json
{
  "hex_honesty": {
    "low":  ["你把自己的利益放得很前面，說謊對你沒什麼心理負擔。", "…", "…"],
    "high": ["你很看重誠信，能不騙人就不騙，即使會吃虧。", "…", "…"]
  },
  "hex_emotionality": {
    "low":  ["…", "…", "…"],
    "high": ["…", "…", "…"]
  }
}
```

文案要調整或增補變體時不用改程式碼。

## 5. System Prompt 組裝

### 規則

1. 三個區塊：極端值行為準則、`character`、外觀文字
2. **任一區塊為空 → 整段（含標題）不輸出**。不要留 `【這個人】：` 後面接空字串，模型看到空欄位會自行編造
3. 建角完成後產生一次，存進資料庫，之後每次呼叫直接取用
4. **逐字元固定不變**——這是 llama-server KV cache 能命中的前提（見《01-3》§5）

```
func build_system_prompt(traits: Array[String], character: String, appearance: String) -> String:
    var p := "你正在扮演一個遊戲角色。\n\n"
    if not traits.is_empty():
        p += "【行為準則】\n"
        for t in traits:
            p += "-%s\n" % t
        p += "\n"
    if character.strip_edges() != "":
        p += "【這個人】%s\n\n" % character
    if appearance.strip_edges() != "":
        p += "【你的外表】%s\n\n" % appearance
    p += "請嚴格遵循上述設定，依當前局勢做出決策與回應。"
    return p
```

### 產出範例

```
你正在扮演一個遊戲角色。

【行為準則】
- 你把自己的利益放得很前面，說謊對你沒什麼心理負擔。
- 面對衝擊性的事，你的反應通常比旁人平淡許多。
- 你不喜歡社交，跟人講話容易疲乏，通常不會主動延續話題。

【這個人】崩塌前是機房維修員，獨自活過三次斷電。說話很短，不耐煩時會發出鼻音。最在乎自己的東西不被別人碰。

【你的外表】你剪得很短的灰髮，左手戴著皮手套。

請嚴格遵循上述設定，依當前局勢做出決策與回應。
```

## 6. 儲存結構

```json
{
  "hexaco_input": {
    "hex_honesty": 15, "hex_emotionality": 10, "hex_extraversion": 20,
    "hex_agreeableness": 40, "hex_conscientiousness": 70, "hex_openness": 50
  },

  "personality": {
    "diligence": 70, "courage": 64, "sociability": 20, "morality": 23,
    "stability": 90, "romanticism": 34, "curiosity": 50, "grudge": 40,
    "greed": 69, "honesty": 15
  },

  "system_prompt": "你正在扮演一個遊戲角色。\n\n【行為準則】\n- 你極度自私狡猾…"
}
```

| 欄位 | 讀寫 | 說明 |
| --- | --- | --- |
| `hexaco_input` | **唯讀** | 建角紀錄，遊戲中不再變動 |
| `personality` | 引擎讀寫 | 睡覺反思時單項 ±3 |
| `system_prompt` | **唯讀** | 建角時產生後固定，每次呼叫 LLM 直接注入 |
