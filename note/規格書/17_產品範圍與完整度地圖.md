# 17_產品範圍與完整度地圖

**用途**：跨系統、跨階段的建置完整度總覽，回答「相對於完整版上限，現在做到哪、下一步排哪」。

**跟《00》《99》的分工**（三份不重複，只互相指路）：

| 文件 | 回答什麼 |
| --- | --- |
| 《00》文件索引 | 這份**規格**寫完拍板了沒（已定案／含推測／待填…） |
| 《99》 | 單一個**設計問題**決定了沒（P 編號逐項決策帳本） |
| 本文件 | 相對完整版上限，**實際做進遊戲了沒**（跨系統、按階段） |

**維護方式**：不用每次整庫重掃。只在某個領域有進度時（issue 關閉、PR 合併、新拍板）更新
下面「完整度地圖」對應那一列即可，其餘列維持原狀。若某列很久沒動、你懷疑過期，
再指名該領域重查，不用全表重查。
