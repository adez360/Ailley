## 1. 功能範圍

| 功能 | 說明 |
| --- | --- |
| 角色建立 | 六維滑桿 ＋ 自由文本 ＋ 外觀挑選 |
| 角色庫 | 已建立但尚未投放的角色 |
| 角色投放 | 把角色放進世界，初始上限 3 人，可課金至最多 10 人 |
| 官方模板 | 50 個 NPC 模板，可直接選用或作為隨機範例來源 |

## 2. 面板流程

```

└──────────────┬──────────────────────────────────────────────┘
               │ 點「＋」
               ▼
┌─────────────────────────────────────────────────────────────┐
│                       建角面板                                │
│                                                              │
│  ┌─ 分頁 1：基本 ──┐ ┌─ 分頁 2：個性 ─┐ ┌─ 分頁 3：外觀 ─┐  │
│  │ 姓名            │ │ 6 個滑桿       │ │  【待規劃】     │  │
│  │ 年齡            │ │ character 文本 │ │                │  │
│  │ 性別            │ │ 極端項計數     │ │                │  │
│  └────────────────┘ └────────────────┘ └────────────────┘  │
│                                                              │
│                    [ 隨機範例 ]  [ 儲存 ]                     │
└──────────────┬──────────────────────────────────────────────┘
               │ 儲存
               ▼
        ┌──────────────┐
        │  存檔驗證     │ ── 不通過 ──► 提示並擋下

               │ 通過

   ┌────────────────────────────┐

                ▼
```

## 3. 分頁 1：基本資料

| 欄位 | 元件 | 限制 |
| --- | --- | --- |
| `name` | 文字輸入 | 上限 12 字，必填 |
| `age` | 數字輸入或滑桿 | 16–70，預設 30 |
| `gender` | 三選一按鈕 | `male` / `female` / `other` |

---

## 4. 分頁 2：個性

### 4-1 六維滑桿

| 中文 | 英文欄位 | 0% 端標籤 | 100% 端標籤 |
| --- | --- | --- | --- |
| 誠實謙遜 | `hex_honesty` | 狡猾自私 | 真誠無私 |
| 情緒起伏 | `hex_emotionality` | 冷酷無情 | 敏感多愁 |
| 外向性 | `hex_extraversion` | 孤僻自閉 | 社交狂熱 |
| 友善性 | `hex_agreeableness` | 充滿敵意 | 溫和包容 |
| 嚴謹性 | `hex_conscientiousness` | 散漫衝動 | 嚴密自律 |
| 開放性 | `hex_openness` | 傳統保守 | 獵奇創新 |

**UI 要求**：

- 預設 50，最小刻度 5
- 兩端標籤必須同時顯示，玩家才知道推向哪邊是什麼
- **滑桿進入極端區（≤25 或 ≥75）時要有視覺回饋**【推測待確認】：例如該滑桿變色或加上圖示

### 4-2 極端項計數器

面板需即時顯示：

```
個性強度：●●○○     2 / 4
提示：再推 0 個滑桿就達標了
```

| 狀態 | 顯示 |
| --- | --- |
| 未達下限 | 紅字「再把 N 個滑桿推向兩端，這個角色才有個性」 |
| 達標（2~4） | 綠字「這個角色有個性了」 |
| 超過 4 | 黃字「推太多了，人設會互相打架。請減少 N 個」 |

### 4-3 `character` 文本框

| 項目 | 規格 |
| --- | --- |
| 型別 | 多行文字框 |
| 上限 | 250 字 |
| 必填 | 否 |
| 即時字數 | 顯示 `47 / 250` |

placeholder：

```
崩塌前是機房維修員，獨自活過三次斷電。
說話很短，不耐煩時會發出鼻音。
最在乎自己的東西不被別人碰。
```

下方小字：「寫外表、口癖、過去經歷、他最在乎什麼都可以。不要寫能力或數值。」

### 4-4 存檔驗證

定義：**極端項** = 該滑桿 ≤ 25 或 ≥ 75。

| 情況 | 極端項數量要求 |
| --- | --- |
| `character` 有填 | 2 ≤ n ≤ 4 |
| `character` 留空 | 3 ≤ n ≤ 4 |

未達標時**擋下存檔**。

## 5. 分頁 3：外觀　【待規劃】

### 5-1 已確定的部分

- 資料為陣列 `appearance[]`，可儲存多筆
- 每筆含 `slot`（部位）／`item_id`（素材編號）／`label`（中文短句 ≤20 字）
- 存檔時由 `build_appearance_text()` 把所有 `label` 串成一段自然語言
- 產生的文字寫入 `system_prompt` 常駐段

### 5-2 提案 slot 清單　【推測待確認】

| `slot` | 中文 | 可存筆數 | 必填 | 備註 |
| --- | --- | --- | --- | --- |
| `body` | 體型 | 1 | ✔ | 精瘦／壯碩／嬌小… |
| `hair` | 髮型髮色 | 1 | ✔ |  |
| `face` | 臉部特徵 | 1 | ✗ | 疤痕、雀斑、鬍子 |
| `eyes` | 眼睛 | 1 | ✔ |  |
| `top` | 上衣 | 1 | ✔ |  |
| `bottom` | 下著 | 1 | ✔ |  |
| `shoes` | 鞋 | 1 | ✗ |  |
| `accessory` | 配件 | 最多 3 | ✗ | 手套、眼鏡、項鍊… |

### 5-3 組句規則　【推測待確認】

`build_appearance_text()` 依固定順序串接：

```
體型 → 髮型 → 眼睛 → 臉部特徵 → 上衣 → 下著 → 鞋 → 配件
```

**輸出範例**：

```
你身形精瘦，剪得很短的灰髮，一雙灰藍色的眼睛，左眼下方有一道舊疤，
穿著一件磨損的皮外套與深色工作褲，左手戴著皮手套。
```

- 空的 slot 整段略過，不輸出「無」
- 連接詞由固定模板組裝，不呼叫 LLM

## 6. 隨機範例按鈕

| 位置 | 行為 |
| --- | --- |
| 分頁 2 | 從 50 個 NPC 模板庫抽一段填入 `character` |
| 分頁 3 | 隨機組合一套外觀 |
| 全局 | 【推測待確認】是否提供「整個角色隨機」按鈕 |

> ⚠️ 50 個 NPC 模板的隨機產生器**必須套用同一條存檔驗證式**（§4-4），否則隨機村民會全部趨中，沒有個性。

## 7. 角色庫與投放

### 7-1 角色庫

| 項目 | 規格 |
| --- | --- |
| 顯示內容 | 立繪縮圖、姓名、六維雷達圖【推測待確認】、是否已投放 |
| 可執行操作 | 編輯（僅未投放者）、刪除、投放、複製 |
| 容量上限 | 【推測待確認】無上限 |

> ⚠️ **已投放的角色不可編輯**。`personality` 在遊戲中會因反思變動，回頭改滑桿會造成資料不一致。
> 

### 7-2 投放機制

| 項目 | 規格 |
| --- | --- |
| 初始上限 | 3 人 |
| 課金上限 | 最多 10 人 |
| 投放時機 | 世界開始前或進行中【推測待確認】 |
| 投放後 | 進入世界，開始跑決策循環 |
