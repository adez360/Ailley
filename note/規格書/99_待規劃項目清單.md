## P-03　是否縮減傳送項目讓 AI 判斷更聚焦

| **類型** | 待決策 |
| --- | --- |
| **現況** | 每 tick 全量注入約 1,100~1,300 token |
| **對應章節** | 《01-3》§4、《04》§4-2 |
| **影響文件** | 01-3 / 04 |

**核心問題**：塞越多資料進去，AI 每項都只輕微參考一點，行為會趨向平均值。縮減注入項目能讓決策更聚焦，但要先決定「誰來決定給什麼」。

### 三個方案

|  | A：固定全量 | B：情境預測式 | C：兩段式按需 |
| --- | --- | --- | --- |
| 誰決定給什麼 | 全給 | 引擎 | AI |
| 呼叫次數 | 1 | 1 | 1~2 |
| token 降幅 | — | 40~60% | 50~70% |
| tick 延遲 | 基準 | 不變 | 最壞翻倍 |
| 需改 GBNF | 否 | 否 | 是 |
| 需改 DES 時序 | 否 | 否 | 是 |
| 實作成本 | 無 | 中 | 高 |
| 風險 | AI 注意力分散 | 引擎誤判導致缺資料 | 小模型濫用或不會用 |

**建議**：B 為主線，C 列入迭代二。

### 方案 B 的情境對照表（若採用，需填完）

| 情境 | 帶入的 Tier 1 資料 | 確認 |
| --- | --- | --- |
| 在商店 / 交易中 | 金錢、完整庫存、商品清單 | ☐ |
| 有他人在場 | 在場者 4 維關係、可社交行動 | ☐ |
| 在森林 / 獨處 | 地點資源、可工作行動（不帶關係） | ☐ |
| 剛被攻擊 / 目擊 | 對象關係、可用防禦行動 | ☐ |
| 睡醒第一個 tick | `today_plan` 模板、昨日摘要 | ☐ |
| 其他： |  | ☐ |

### 需要決定的事

| # | 問題 | 決定 |
| --- | --- | --- |
| 1 | 採用哪個方案？ |  |
| 2 | 若採 B：情境對照表要涵蓋哪幾種情境？ |  |
| 3 | 若採 C：`request_info` 可查詢的項目清單？ |  |
| 4 | 若採 C：追加查詢上限幾次？ |  |

## P-10　`words_to_creator` 觸發機率與生成文案

| **類型** | 待填 |
| --- | --- |
| **對應章節** | 《01》§1-4、《04》§4-3 |

### 已確定的部分

- 內容定位：角色對「自己被設定成這種性格」想說的一句話
- 生成時機：建角存檔時，僅此一次，`content` 之後唯讀
- **觸發時機：玩家用天神之石對該角色說話時，一生僅觸發一次**
- 說出方式：注入該次 prompt，由 AI 自行決定要不要真的說出口
- 聽眾：**只有玩家看得到**，不進入其他 NPC 的對話事件與記憶

## P-13　極端值文案語氣與變體

| **類型** | 待決策 |
| --- | --- |
| **對應章節** | 《01-1》§4 |

### 問題一：語氣強度

現行 12 條文案全為絕對句（「毫不猶豫」「從不」「總在」「極度」），這是比給數字更強的行為約束，與「給 AI 自主決策最大空間」的方向相反。

| 現行（規定行為） | 提案（只給傾向） |
| --- | --- |
| 你極度厭惡社交，會用最簡短冷漠的字眼結束對話。 | 你不喜歡社交。跟人講話容易疲乏，通常不會主動延續話題。 |
| 你極度自私狡猾，為了利益會毫不猶豫地欺騙與背叛。 | 你把自己的利益放得很前面，說謊對你沒什麼心理負擔。 |

差別：前者規定「怎麼講話」，後者只給偏好，讓 LLM 自己決定這次要不要例外。偶爾破例才像人。

### 問題二：50 個 NPC 讀起來會很像

12 條文字、每人抽 2~4 條，模板庫必然大量重複。

**提案**：每個維度每一端準備 3 種語氣變體隨機抽，`hexaco_traits.json` 從 12 條變 36 條，程式碼不用改。
