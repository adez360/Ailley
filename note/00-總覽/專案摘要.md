# 專案摘要

> [!info] 定位
> 一個基於 Web 的 2D 像素風格（類似《星露谷物語》）微型村莊。村莊內的 NPC 不由固定腳本控制，而是由大語言模型 (LLM) 與代理框架 (Agent Framework) 驅動；NPC 擁有自己的性格、記憶與日常作息，能自主決定行動、與環境互動，並與玩家及其他 NPC 自然對話、社交。

## 核心特色
- **自主思考的 NPC**：依時間、需求與性格決定下一步（早上務農、晚上去酒館）。→ [[AI 角色系統]]
- **長期記憶系統**：記住事件、對話與人際關係。→ [[記憶與認知系統]]
- **動態環境互動**：行為改變世界狀態，並能意識到環境變化。→ [[世界與時間系統]]
- **Web 即時互動**：瀏覽器即可以上帝／第一人稱視角觀察村莊生態，隨時介入。
