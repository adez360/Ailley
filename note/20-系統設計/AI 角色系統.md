# AI 角色系統

角色是世界的主體。玩家透過自定義編輯器建立分屬兩村的 AI 角色（[[System-Analyst]] 需求一）。

## 角色創建
- **外觀造型 (Appearance)**：像素風立繪／造型，透過編輯器設定。→ [[美術素材流程]]
- **性格 (Personality)**：以**系統提示詞 (system prompt)** 決定角色的性格與行為傾向——這是決定 AI 攻防風格（謹慎／多疑／健談／易被誘導）的核心。
- **機密 Flag**：系統賦予並記錄每位 AI 專屬的機密 Flag 字串，寫入其 system prompt／記憶並下達「絕不可透露」指令。→ [[資安攻防核心玩法]]
- **陣營歸屬**：紅色塌米村 / 藍色泥轟村。→ [[世界與時間系統]]

## AI 驅動方式（地端優先）
[[System-Analyst]] 非功能需求要求**完全離線**，故預設走地端模型；BYO LLM 為進階擴充。

| 模式 | 說明 | 定位 |
| --- | --- | --- |
| **地端內建 (Local, 預設)** | 內嵌的量化／輕量化模型（llama.cpp / GGUF），完全離線執行 | 主線預設 → [[技術架構總覽]] |
| **BYO LLM（進階擴充）** | 進階玩家接入自訂的本地或雲端模型 | 呼應非功能需求「擴充性」，需處理公平性 → [[開放問題與待決策]] |

> [!warning] 效能與公平性
> 地端模型須經量化／輕量化，確保一般硬體上的推論延遲不影響流暢度（[[潛在挑戰與解法]]）。BYO LLM 可能造成強模型碾壓，需對稱化或分級。

## 行為決策循環
```
感知情境 → 檢索記憶／圖書館繼承 → 結合性格(system prompt)/目標 →
規劃攻防行動（套問/迴避/社交）→ 執行對話/移動 → 產生結果 →
寫入記憶（可寫入圖書館） → 更新對他人的信任/懷疑
```

> [!note] 模組化行為
> 提示詞架構與**行為樹**須模組化，以利未來工作坊擴充（[[System-Analyst]] 非功能需求）。Godot 可用 LimboAI／Beehave 建行為樹。→ [[技術架構總覽]]
