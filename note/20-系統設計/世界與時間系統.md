# 世界與時間系統

- **時間流**：以「遊戲日」為基本單位，可調速（暫停 / 1x / 加速）。一日分為晨／午／昏／夜。
- **地圖**：共享的山谷，含住宅區、市集、農田、礦山、廣場、野外等機能區。→ [[參考素材]]
- **資源**：食物、材料、金錢等，驅動經濟與生存壓力。
- **持久化**：世界狀態與角色記憶跨日保存，形成連續的「故事線」。→ [[記憶與認知系統]]
