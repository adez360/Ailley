# 記憶與認知系統

讓行為可信的關鍵。參考生成式代理人 (Generative Agents) 的 memory stream + 重要性評分 + 反思機制。

## 結構
- **短期記憶 (Working Memory)**：當前情境、最近互動。
- **長期記憶 (Long-term / Vector Retrieval)**：重要事件、人際關係、情感印象。
- **反思 (Reflection)**：角色定期將經歷歸納成更高層的信念（例：多次被欺騙 → 「我不該輕易相信陌生人」）。

## 關係網
角色對彼此維護好感／信任／恩怨值，驅動社交行為，也是 [[內心想法視窗|內心面板]] 揭露的重點之一。

> [!bug] 挑戰：記憶檢索不精準
> 隨時間推移，記憶累積過多 → AI「忘記」重點。
> **解法**：雙層記憶（短期 Working Memory + 長期 Vector Retrieval）+ 定期「總結與反思」。詳見 [[潛在挑戰與解法]]。
