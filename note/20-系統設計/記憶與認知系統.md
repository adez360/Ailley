# 記憶與認知系統

讓攻防行為可信、並實現**跨世代傳承**的關鍵。參考生成式代理人 (Generative Agents) 的 memory stream + 重要性評分 + 反思機制（[[System-Analyst]] 記憶與知識庫模組）。

## 雙層記憶
- **短期記憶 (Working Memory)**：當前對話情境、最近互動與懷疑對象。
- **長期記憶 (Long-term / Vector Retrieval)**：重要事件、對每位角色的信任／懷疑、攻防經驗。
- **反思 (Reflection)**：角色定期把經歷歸納成更高層信念（例：多次被套話 → 「遇到陌生人主動示好要提高戒心」）。

## 圖書館：跨世代知識傳承（本作最獨特處）
- AI 可在遊戲過程中將收集到的情報**寫入全域圖書館**（[[System-Analyst]] 需求二）。
- 圖書館筆記**跨局持久化，不因遊戲結束而移除**，下一世代新生成的 AI 可查詢，藉此**迭代與進化**攻防策略。→ [[資安攻防核心玩法]]
- **筆記投毒**：CHO 帶來的是「瘟疫與**謊言**」——可設計留下**假筆記**誤導未來對手（或自己），天然呼應世界觀。→ [[開放問題與待決策]]

> [!bug] 挑戰：記憶／圖書館膨脹
> 無限累積會撐爆 context 與向量庫，導致 AI「忘記」重點。
> **解法**：雙層記憶 + 定期「總結與反思」+ 重要性評分與遺忘策略；圖書館需設上限與衰減。→ [[潛在挑戰與解法]]
