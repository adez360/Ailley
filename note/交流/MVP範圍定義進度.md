## 我認為值得補充、但你還沒提過的

這些是我自己掃出來、你可能還沒想到要問的：

1. **`murmur`（自語）目前只定義了「一次性、不開 Conversation」，但沒定觸發時機**——AI 什麼情況下會選擇自語而不是單純 `idle`？如果沒有明確情境，這個動作會變成 AI 永遠不選的死動作。
2. **`bleeding`（流血）沒有定義會不會導致昏迷**——照現有設計，`bleeding` 持續扣 `health`，理論上放著不管會扣到 0 觸發昏迷。這是預期行為（流血不止會昏迷，很合理）還是要另外加個下限保護？現在沒寫清楚。
3. **跑步（P-29）沒有定義 Agent 要不要主動決定跑**——如果只有玩家能跑，那「AI 角色移動速度」跟「玩家移動速度」就會不對稱，玩家永遠比較快；如果 AI 也能跑，那什麼情況下 AI 會選擇跑（趕時間？逃跑？）也要有判斷依據，不然這個功能對 AI 端等於沒接上。
4. **藥草鋪「治療」跟「止血」是不是同一次流程**（P-27 已經記錄這題，但值得提醒：這決定會影響 UI 要不要分兩個互動選項）。
5. **06 新增的 `decision_source`／`model_name` 沒有講清楚誰可以事後改**——投放後的角色能不能中途換模型（例如本機模型效果不好想換雲端）？跟《05》「已投放角色不可編輯」的既有規則（`personality` 會因反思變動）是不是也套用在這兩個新欄位上，還沒交代。
