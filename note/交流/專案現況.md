# 專案現況

給人看的總覽。**技術細節不寫這裡**，那些在 `技術/` 底下。

## 一句話

Ailley 是由 LLM 驅動的 2D 像素村莊。角色分兩種：你操作的 Player，
和由 AI 操作的 Agent。核心目標是養一個有自己人格與記憶的夥伴，並且能
跟別人的 Agent 交流。

## 現在能玩到什麼

- 走進真的村莊地圖：家／藥草鋪／餐酒館／涼亭／天神之石 5 個地點
- 場上的 Agent 用 LocalLLM／RemoteLLM 即時生成行程決策與對話台詞，不是模板句
- Agent 有情緒、會累積記憶，決策會反映當下心情、人格與過去發生的事
- Agent 看到沒見過的人會愣一下；視覺感測只看距離與視線遮蔽，不判斷朝向（全方位偵測）
- 可以捏角色（六維人格滑桿）、存進角色庫、投放進世界
- 昏迷取代死亡的 MVP-1 機制仍在（血歸零昏迷、可被搬走搭救）；同時真正的
  死亡／墓園全套系統（死亡狀態機、安葬、墓碑三欄位、AI 角色復活）
  已大半落地，整批端到端驗證（issue #388）還沒收尾，暫時兩套並存
- 用滑鼠點角色，鏡頭就跟著他跑；點空地取消，鏡頭移回自己身上
- 天神之石：純觀察者模式靠它跟角色說話
- Agent 可以嘗試說服（persuade）其他角色，成敗交給對方的模型自己判斷；
  說服對象也可以是玩家本人，會跳出 Y/N 對話框
- 按 `E` 走近搭話、按 Enter 打字讓自己的角色說話；工作站／販賣機也走同一顆 E 鍵
- 藥草鋪／餐酒館的販賣機已上架完整品項，酒類真的會累加 `alcohol` 數值
- 物品欄單格堆疊上限 30 個已強制生效，超量自動開新格
- 吃飯／喝水／送禮／被說服／搬運／進入異常狀態現在都會寫進當日事件記錄，
  供睡眠反思時評分用
- 睏倦／力竭狀態會影響成功率與行動時長
- 按 `` ` `` 開除錯主控台，可以指揮角色、看數值、開各種疊圖
- 關掉遊戲重開，角色與世界狀態都還在（JSON 存檔線是正式線；SQLite 是平行
  開發中的替代後端，尚未切換上場，見 [[存檔]]「SQLite 後端現況」）

### 化身者（player 走動操作）已經寫完，只是還沒有按鈕能按到

`Ailley/scripts/character/player.gd` 本身已經有完整的移動、E 鍵互動（工作站／販賣機／搭話三選一）、
物品欄／快捷欄 UI（issue #463）——**程式碼已經支援化身者**，`GameManager.deploy_from_library(id, true)` 這個函式也早就存在。缺的只是**入口**：
角色庫面板的「投放」按鈕目前固定呼叫不帶 `as_player` 的版本（一律投放成
Agent）；建角面板頂端已有『AI 角色／由我操控』toggle（#954）。現在唯一能真正操控一個角色走動的方法是**除錯主控台**
下 `embody <id>` 指令（內部呼叫 `GameManager.deploy_from_library(id, true)`）
——這條路能玩、能測，但一般玩家在正常選單流程裡還按不到。相關的一整批
issue（#369～#378，group 1）大多已完成，等 #378 端到端驗證收尾。
