# 專案現況

給人看的總覽。**技術細節不寫這裡**，那些在 `技術/` 底下。

## 一句話

Ailley 是由 LLM 驅動的 2D 像素村莊。角色分兩種：你操作的 Player，
和由 AI 操作的 Agent。核心目標是養一個有自己人格與記憶的夥伴，
並且能跟別人的 Agent 交流。

## 現在能玩到什麼

- 走進一張涵蓋 MVP 5 個地點（家／藥草鋪／餐酒館／涼亭／天神之石）的村莊地圖，用 WASD 移動
- 場上有兩隻 Agent，會照時間表去不同地點（早上在家、九點去藥草鋪工作）
- 走近按 `E` 可以搭話，對方會依自己的心情與對你的好感度回話
- Agent 看到沒見過的人會愣一下
- 用滑鼠點角色，鏡頭就跟著他跑；點空地取消，鏡頭移回自己身上
- 按 Enter 可以打字讓自己的角色說話
- 按 `` ` `` 開除錯主控台，可以指揮角色、看數值、開各種疊圖

## 還沒有的

| 缺什麼 | 影響 |
| --- | --- |
| **AI 產生的台詞** | 現在的對話是模板句，看得出是罐頭 |
| **AI 安排的行程** | Agent 照死板的時間表跑，不會因為餓了自己去吃 |
| **記憶** | Agent 記得對你的好感度，但不記得發生過什麼事 |
| **存檔** | 關掉遊戲什麼都不留 |
| **物品與金錢** | 沒有生產、沒有買賣 |
| **交誼區** | 完全沒開始，目前純單機 |

## 下一步

接 LLM 的對話（技術上叫 Step 1）。做完之後 Agent 講的話就是模型即時生成的，
會反映它的人格、心情、以及跟你的關係。

**這一步做完最該注意的是成本** —— 目前對話輪數沒有硬上限，
兩隻 Agent 有可能一直客套下去，而每一輪都是一次付費請求。
見 [[決策]] 裡的待決事項。

## 目前已知的問題

| 問題 | 嚴重度 | 說明 |
| --- | --- | --- |
| 「家」是寫死的同一間 | 低 | 所有角色餓了累了都會被導向同一個地點，多間房子的建角分配邏輯還沒做 |
| LLM 成本無上限 | **高** | 接上對話之後才會真的暴露，見上 |
| 完整版還有 10 個地點沒做 | 低 | 《規格書 07》定義 15 個地點，MVP 只做了 5 個 |
