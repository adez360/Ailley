# 專案現況

給人看的總覽。**技術細節不寫這裡**，那些在 `技術/` 底下。

## 一句話

Ailley 是由 LLM 驅動的 2D 像素村莊。角色分兩種：你操作的 Player，
和由 AI 操作的 Agent。MVP-1 設計上玩家不走動、只透過天神之石介入，
核心目標是養一個有自己人格與記憶的夥伴，並且能跟別人的 Agent 交流。

## 現在能玩到什麼

- 走進真的村莊地圖：家／藥草鋪／餐酒館／涼亭／天神之石 5 個地點
- 場上的 Agent 用 LocalLLM／RemoteLLM 即時生成行程決策與對話台詞，不是模板句
- Agent 有情緒、會累積記憶，決策會反映當下心情、人格與過去發生的事
- Agent 看到沒見過的人會愣一下
- 可以捏角色（六維人格滑桿）、存進角色庫、投放進世界
- 昏迷取代了死亡：血歸零會昏迷，能被其他角色搬走搭救
- 用滑鼠點角色，鏡頭就跟著他跑；點空地取消，鏡頭移回自己身上
- 天神之石：player 沒有身體時，靠它跟角色說話，是 MVP-1 玩家唯一的介入管道
- Agent 可以嘗試說服（persuade）其他角色，成敗交給對方的模型自己判斷
- 按 `E` 走近搭話、按 Enter 打字讓自己的角色說話（player 操作方式，MVP-1 之後會被天神之石取代）
- 按 `` ` `` 開除錯主控台，可以指揮角色、看數值、開各種疊圖
- 關掉遊戲重開，角色與世界狀態都還在（存檔已落地）
