# Localization

目標是把寫死的文字抽出來，讓遊戲能換語系。技術細節見 [[在地化]]。

## 現在的狀態

**UI 文字全部抽完，中英文都能跑。** 共 148 條（玩家看得到的 74 條、debug 主控台 74 條）。
英文是照中文原意翻的，**不是專業譯文**——意思正確，語氣未必到位。

## 還沒做的三件事（都是功能缺口，不是翻譯漏掉）

- **角色沒有顯示名**——NPC 直接叫 `agent`／`agent2`，卡在角色命名系統還沒做
- **地點沒有顯示名**——`farm`、`restaurant` 這些 key 直接被印出來
- **失敗原因還是代碼**（`TALK_TOO_FAR`），但玩家目前看不到這些訊息，先沒處理

另外，遊戲裡沒有切換語系的正式介面，只有 debug 主控台的 `locale` 指令。

## 已決定（2026-08-15，都是「先不做」，之後可回頭再議）

- 英文譯文先不找人潤，現階段意思對就夠
- 先不加日文（字型這關已經過了，見 [[在地化]]，之後要加隨時可以）
- 角色命名系統先留著，之後再做
