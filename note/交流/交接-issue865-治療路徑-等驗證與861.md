# 交接：issue #865（藥草鋪治療沒有任何呼叫端）

## 背景

`injury`／`bleeding` 流血狀態目前沒有任何手段能治好——`medicine` 道具的
`effect_injury: -30.0` 接不到，藥草鋪駐點 NPC 的 `_complete_treatment()`
也沒有任何呼叫端（詳見 issue #865 本文）。使用者拍板（2026-09-01）：**兩條
路徑都做**，但藥草鋪 NPC 治療路徑要等 issue #861／PR #862（`_treatment_start_minute`
的 JSON int/float reload bug）先合併，避免治療流程一接通就帶已知 bug。

分支：`fix/injury-cure-paths`，worktree
`.claude/worktrees/fix+injury-cure-paths`（已從最新 main 開出）。

## 進度

### 1. medicine 道具治療 —— 已完成並驗證，等開 PR

玩家與 AI 角色兩側都已接通：

- **玩家**：`Character.use_selected_item()` 原本用
  `category == "food" or "drink"` 判斷是否為消耗品，`medicine` 分類是
  `carry` 永遠被擋掉。改成判斷物品定義裡有沒有任一個 `effect_*` 欄位
  （不看 category），自然涵蓋 `medicine` 的 `effect_injury`，也不會誤放行
  `knife`／`battery` 這些沒有 `effect_*` 的 `carry` 道具。
- **AI 角色**：新增 `medicate` 決策動作（`Character.medicate()` +
  `Character._find_curative_slot()`，跟 `eat()`／`drink()` 同一套「吃掉
  背包裡已經有的東西」形狀），接上 `AISchema.ALLOWED_ACTIONS` /
  `IMPLEMENTED_ACTIONS`、`prompt_builder.gd` 的因果鏈說明（比照 buy→eat
  的既有措辭）、`Agent.resolve()`／`_pursue_medicate_task()` 執行層，
  以及 `status_panel.gd` 的動作顯示名稱。

godot-ai game_eval 驗證過：玩家 `use_selected_item()`（injury -30、下限
夾制 0、knife 這種無效果道具正確擋下不消耗）；AI `resolve("medicate")`
（無藥品時擋下、有藥品時放行）與完整的 `_pursue_medicate_task()` 派發
（injury 下降、道具消耗、`_daily_events` 記一筆治傷事件、任務收尾）。

### 2. 藥草鋪 NPC 治療路徑 —— 未開始，卡在 #861／PR #862

`_send_to_herb_shop_for_treatment()`／`_complete_treatment()` 本身邏輯完整
但無呼叫端。規格書寫的「昏迷 30 分鐘無人搬走→自動送醫」這條觸發已被 #379
的死亡流程取代（見 `note/技術/昏迷狀態機制.md`「Phase 2 現況」），剩下唯一
還可能成立的觸發是「把昏迷者搬到藥草鋪」，但目前 `haul` 機制**只要有人搬
就結束昏迷，不檢查搬到哪裡**——沒有比照 `bury()`（安葬要用
`_is_at_cemetery()` 檢查落點）那樣的「到達目的地才觸發」判定。要接通這條，
需要新增一個類似 `bury()` 的「送醫」verb，是新設計不是補一行呼叫。

**下一步**：
1. `gh pr view 862 --json state,mergedAt` 確認 #862 是否已合併
2. 已合併：確認 #861 也修完（依 `issue-861-blocked-on-pr862` memory，worktree
   `.claude/worktrees/fix+incapacitation-emotion-float-reload` 已存在但無 commit）
3. 設計新的「送醫」verb（比照 `bury()` 的 `_is_at_cemetery()` 判定模式），
   接上 `_send_to_herb_shop_for_treatment()`
4. 順手更新 `note/規格書/07_地點/藥草鋪.md`「治療」一節與《99》P-27
   #2——「30 分鐘無人搬自動送醫」這條規格文字已經是 #379 之後的過時描述，
   需要一併修正，不只是補程式碼
