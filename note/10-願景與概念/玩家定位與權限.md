# 玩家定位與權限

> [!important] 關鍵規則（原構想第 5、6 點）
> 玩家不能直接操作 NPC（角色），但能操作全局事件。玩家的影響力一律是「間接」的——你改變的是世界，不是角色的意志。

| 玩家 **可以** 做 | 玩家 **不能** 做 |
| --- | --- |
| 創造、設定、投放 AI 角色 | 直接操控角色的每一步行動 |
| 設定角色的性格、外觀、背景、日常安排 | 替角色說出每一句對話 |
| 觸發全局事件（天氣、災害、節慶、資源變動） | 強制角色違背其性格行事 |
| 在世界中放置建築、資源、地標 | 直接讀取其他玩家角色的「內心記憶」（除非開放） |
| 對「自己的」角色下達高階引導（目標、價值觀提示） | 即時操控移動／戰鬥 |
| 查看**自己**角色的內心想法、記憶與決策理由 | 查看其他玩家角色的內心（只能看外顯行為） |
| 觀看世界、回放、閱讀 AI 日誌 | 暫停／回溯其他玩家的角色 |
