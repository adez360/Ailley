# 村民 AI 規格書

原則：**LLM 只決定「想做什麼」，做不做得到由引擎判定。**

## 4. 可做的行為

### A. 溝通

`說話`（對某人）、`喊話`（附近所有人都聽得到）、`悄悄話`（只有對方聽得到）

### B. 需要對方同意才會成功

握手、擁抱、送禮、給錢、結婚、離婚

### C. 不需同意（引擎判成敗）

偷竊、搶劫、破壞樂器、攻擊、抓捕（**需要兩個人同時進行**）、舉報

### D. 工作與消費

打獵、採草藥、釣魚、表演、買東西、賣東西、治療、吃飯、喝酒

### E. 動作與移動

移動、奔跑、蹲下、抱頭、舉手、大叫、摔東西、飛吻、跟隨、展示物品、巡邏、自首、睡覺、發呆

**沒有職業設定。** 村民自己決定今天要做什麼。

## 5. 人格（6 項，0–100，固定不變）

數值只用來寫成一段人格描述，塞進該村民的 system prompt。**每天只有睡覺時可能微調 ±3。**

| 參數 | 高的樣子 | 低的樣子 |
| --- | --- | --- |
| 勤勉度 | 閒不下來，看別人發呆會煩 | 能不動就不動，寧可餓也不想工作 |
| 膽識度 | 不怕森林深處，危險反而興奮 | 天生膽小，寧可繞路 |
| 社交性 | 看到人就想搭話，獨處會煩躁 | 不喜歡人多，一個人最好 |
| 道德感 | 受不了不守規矩的人，會舉報 | 規則只是建議，拿得到就是我的 |
| 情緒穩定 | 很難被激怒，先想再說 | 一點就著，小事也會失控 |
| 浪漫藝術 | 相信生活需要音樂與愛 | 覺得表演和調情都是浪費時間 |

## 6. 生理狀態（引擎給的事實，LLM 不能自己改）

| 欄位 | 範圍 | 意義 |
| --- | --- | --- |
| 飢餓 | 0–100 | 越高越餓，太餓會變慢 |
| 口渴 | 0–100 | 越高越渴，太渴會變慢 |
| 體力 | 0–100 | 歸零就沒辦法工作 |
| 無聊 | 0–100 | 越高越想找新鮮事、找沒說過話的人 |
| 錢 | 數字 | 買不起就是買不起 |
| 流血 | 有/無 | 不能跑，體力一直掉 |
| 扭到腳 | 有/無 | 不能跑，走得很慢 |
| 割傷手 | 有/無 | 打獵和表演變差 |
| 反省中 | 有/無 | 人在洗心革面所裡 |
| 前科犯 | 有/無 | 出獄後一段時間，別人對他好感會扣 |
| 警戒中 | 有/無 | 巡邏時開啟，看得比較遠 |
| 背包 | 清單 | 沒有的東西不能用 |

> 傷只有藥草鋪能治好。

## 7. 好感度（對每個人分開算，−100 ~ +100）

| 區間 | 標籤 | 給 LLM 的描述 |
| --- | --- | --- |
| 80 ~ 100 | 摯愛 / 至交 | 你願意為他擋刀 |
| 20 ~ 79 | 友好 | 你挺喜歡他的 |
| −19 ~ 19 | 中立 | 沒什麼特別感覺 |
| −20 ~ −79 | 嫌隙 | 看他不太順眼 |
| −80 ~ −100 | 死敵 | 你恨他 |

**開局不是全 0**，每個村民一開始就有喜歡的人和討厭的人。

## 8. 情緒（由 LLM 自己宣告，不是引擎給的）

`興奮` `愉悅` `戀愛腦` `驚恐` `倦怠` `憤怒` `悲傷` `平靜`

> 重點：**引擎只給事件，不給情緒。**
引擎說「B 砸壞了你的樂器」，該生氣、該難過、還是該害怕，由角色自己決定。
同一件事，暴躁的人回 `憤怒`，穩定的人可能回 `悲傷` 然後走開——這個差異就是我們要觀察的。
>

## 9. 輸入格式（每回合給 LLM 的資訊）

```
【現在】第 3 天 19:40（夜晚）
【你的身體】飢餓 87（很餓） 口渴 41 體力 22（快沒力） 無聊 12
【傷病】右手割傷
【錢包】12 元
【背包】草藥 x3（明早會爛）、木笛（耐久 60%）
【位置】村莊廣場
【你看得到】
  - 阿蘭（在長椅上發呆）── 你恨她
  - 老周（正在演奏，前科犯）── 沒什麼特別感覺
【剛剛發生】老周開始演奏，路人丟錢給他
【你上一刻的心情】憤怒
【上一個動作結果】前往藥草鋪 → 失敗：錢不夠（需要 40 元）
```

**兩個必要條件**
1. 數值一定要附中文形容（LLM 對「87」沒感覺，對「很餓」有）
2. 一定要回報上一個動作的**失敗原因**，否則 LLM 會一直重試同一個無效動作

---

## 10. 輸出格式（LLM 每回合要回傳）

```json
{
  "情緒": "憤怒",
  "內心獨白": "沒錢治手，草藥明天就爛了。老周那邊有現金。",
  "說話": "喂，老周，你那笛子借我吹一段。",
  "說話方式": "說話",
  "動作": "表演",
  "對象": null,
  "地點": "村莊廣場"
}
```

| 欄位 | 說明 |
| --- | --- |
| 情緒 | 從第 8 節八選一 |
| 內心獨白 | 一到兩句，說明為什麼這樣做 |
| 說話 | 沒有要說話就填 null |
| 說話方式 | 說話 / 喊話 / 悄悄話 |
| 動作 | 從第 4 節選 |
| 對象 | 村民名字，沒有就 null |
| 地點 | 從第 1 節選 |

---

## 11. 給 AI 組的三條硬規定

1. **不能宣告自己沒有的東西。** 背包沒錢就是沒錢，不能說「我掏出一千塊」。
2. **不能宣告自己的傷好了。** 只有藥草鋪能治。
3. **不能連續發呆超過 3 回合。** 超過會被強制重新決策。
