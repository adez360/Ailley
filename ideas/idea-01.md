# AI Valley — 遊戲設計文件

> 一個由玩家投放的 AI 角色自主生活、社交、成長的開放式模擬世界。
> 玩家不是操控者，而是「造物主／觀察者」：你創造角色、設定環境、引導命運，然後看著他們自己活出一段人生。

---

## 1. 核心概念（一句話）
玩家把自己設計的 AI 角色「投放」進一個共享的山谷世界，角色會依照自己的性格、記憶與日常安排自主行動、彼此互動；玩家無法直接操控角色，只能透過環境、事件與引導去影響這個世界的走向。

### 設計支柱
1. **自主性 (Autonomy)**：角色由 AI 驅動，行為應該是「湧現」的，而非腳本化。
2. **觀察樂趣 (Voyeurism)**：核心樂趣來自觀察與意外，而非操控與勝負。
3. **創作表達 (Authorship)**：玩家透過角色設定與環境設計表達創意。
4. **間接影響 (Indirect Agency)**：玩家的力量是「神之手」式的——下雨、降災、辦慶典，而非直接下指令。

---

## 2. 玩家定位與權限

| 玩家**可以**做 | 玩家**不能**做 |
| --- | --- |
| 創造、設定、投放 AI 角色 | 直接操控角色的每一步行動 |
| 設定角色的性格、外觀、背景、日常安排 | 替角色說出每一句對話 |
| 觸發全局事件（天氣、災害、節慶、資源變動） | 強制角色違背其性格行事 |
| 在世界中放置建築、資源、地標 | 直接讀取其他玩家角色的「內心記憶」（除非開放） |
| 對「自己的」角色下達高階引導（目標、價值觀提示） | 即時操控移動／戰鬥 |
| **查看自己角色的內心想法、記憶與決策理由** | 查看其他玩家角色的內心（只能看外顯行為） |
| 觀看世界、回放、閱讀 AI 日誌 | 暫停／回溯其他玩家的角色 |

> **關鍵規則（原構想第 5、6 點）**：玩家不能直接操作 NPC（角色），但能操作全局事件。玩家的影響力一律是「間接」的——你改變的是世界，不是角色的意志。

## 3. AI 角色系統

### 3.1 角色創建（原構想第 1、3 點）
每個玩家可投放一個或多個 AI 角色，創建時需設定：

- **身分卡 (Identity)**：姓名、年齡、外觀（立繪／像素風格）、出身背景故事。
- **性格 (Personality)**：以特質標籤 + 自由文字描述（例：好奇、易怒、慷慨；「相信努力能改變命運」）。
  - 建議底層用類 Big Five / 自訂特質向量，影響決策傾向。
- **價值觀與目標 (Goals)**：長期人生目標（例：「成為山谷最好的鐵匠」）、短期慾望。
- **日常安排 (Daily Routine)**：預設作息表（起床、工作、用餐、社交、睡眠），AI 會以此為基準但可因事件偏離。
- **技能與職業 (Skills)**：初始職業／專長，影響其在經濟系統中的角色。

### 3.2 AI 驅動方式（原構想第 2 點）
玩家可選擇三種「大腦」來源：

| 模式 | 說明 | 適合對象 |
| --- | --- | --- |
| **自帶金鑰 (BYO Token)** | 玩家提供 OpenRouter / OpenAI / Anthropic 等 API Key，自選模型 | 進階玩家、想要高品質角色 |
| **雲端內建** | 平台提供的託管模型（可能有額度限制或訂閱制） | 一般玩家、新手 |
| **地端 (Local)** | 連接本機 Ollama / LM Studio 等本地模型 | 隱私導向、離線、開發者 |

> 設計建議：將「角色思考品質」與模型脫鉤呈現，避免課金玩家的角色全面碾壓。可用「行動頻率／記憶深度」分級而非「智力」分級，維持公平。

### 3.3 記憶與認知（讓行為可信的關鍵）
- **短期記憶**：當前情境、最近互動。
- **長期記憶**：重要事件、人際關係、情感印象（類生成式代理人的 memory stream + 重要性評分 + 反思機制）。
- **反思 (Reflection)**：角色定期將經歷歸納成更高層的信念（例：多次被欺騙 → 「我不該輕易相信陌生人」）。
- **關係網**：角色對彼此維護好感／信任／恩怨值，驅動社交行為。

### 3.4 行為決策循環
```
感知環境 → 檢索相關記憶 → 結合性格/目標 → 規劃今日行動 →
執行（移動/工作/對話/互動）→ 產生結果 → 寫入記憶 → 影響關係/情緒
```

### 3.5 內心想法視窗（Inner Monologue）
玩家**對自己投放的角色**可以打開一個「內心」面板，看到 AI 行為背後的「為什麼」。這是觀察樂趣與情感連結的核心——你不只看到角色做了什麼，還理解他的動機、糾結與秘密。

可揭露的內容：
- **即時內心獨白**：角色當下在想什麼、為什麼選擇這個行動（從決策循環中暴露出來）。
- **情緒狀態**：當前心情、壓力、慾望（可用簡單的情緒儀表呈現）。
- **對他人的真實看法**：對每位角色的好感／信任／隱藏的恩怨（可能與表面行為不一致——例如表面客氣、內心厭惡）。
- **記憶與反思**：最近寫入的重要記憶、歸納出的信念。
- **決策理由 (Decision Log)**：「我去市集，是因為記得昨天答應了 A 要還錢」這類可追溯的因果鏈。

設計重點：
- **邊界**：內心只對「擁有者」可見。其他玩家的角色一律只能觀察外顯行為——這保留了「猜測他人心思」的社交樂趣與隱私。
- **戲劇張力**：當角色「表面行為」與「內心想法」出現落差時最有趣（口是心非、暗戀、隱忍），UI 應刻意凸顯這種反差。
- **呈現形式**：可做成漂浮的思考泡泡、角色側邊的「心聲」欄，或可展開的詳細面板（資訊密度分層）。
- **與日誌的關係**：每日的角色日記（見第 7 節）即是這份內心狀態的「文學化摘要」。

## 4. 世界與時間系統

- **時間流**：以「遊戲日」為基本單位，可調速（暫停 / 1x / 加速）。一日分為晨／午／昏／夜。
- **地圖**：共享的山谷，含住宅區、市集、農田、礦山、廣場、野外等機能區。
- **資源**：食物、材料、金錢等，驅動經濟與生存壓力。
- **持久化**：世界狀態與角色記憶跨日保存，形成連續的「故事線」。

---

## 5. 全局事件系統（原構想第 6 點）

玩家（或系統）可觸發影響全體角色的事件，這是玩家的主要互動手段：

- **天氣**：晴／雨／暴風雪／乾旱——影響戶外活動、農作、心情。
- **天災**：地震、洪水、火災——製造危機，觀察角色如何應對與互助。
- **資源事件**：豐收、礦脈枯竭、瘟疫——改變經濟平衡。
- **社會事件**：節慶、市集日、選舉、神諭——創造聚集與衝突契機。
- **神諭 / 預兆 (玩家之聲)**：玩家可向全世界或特定區域投放一則「天啟」，角色會「感知」到並自行解讀（仍不等於直接命令）。

> 平衡設計：全局事件應有冷卻時間或資源成本（例如「神力值」），避免玩家濫用導致世界失序。

## 6. 成就與主線目標系統（原構想第 4 點）

提供雙層目標，兼顧開放沙盒與引導性：

### 6.1 玩家成就（Meta 層）
- **觀察成就**：「目睹兩個角色從敵對變成摯友」「見證一場婚禮」「角色活過 100 個遊戲日」。
- **造世成就**：「建立一座有 10 位居民的村莊」「引發一場改變世界的災難後重建」。
- **敘事成就**：解鎖特定戲劇性事件鏈（背叛、復仇、傳承）。

### 6.2 角色目標（World 層）
- 角色自身追求其人生目標，達成時觸發里程碑（玩家可設定或讓 AI 自訂）。
- **主線任務（可選的世界劇本）**：世界可載入一個背景主線（例：「山谷將在 30 日後遭遇大旱，居民能否存續？」），作為鬆散的戲劇框架，而非強制流程。

> 哲學定位：成就是「故事的書籤」，而不是「待辦清單」——獎勵觀察與意外，而非效率。

## 7. AI 日誌系統（原構想第 7 點）

每個遊戲日結束時，由一個 AI（「編年史官 / Chronicler」）自動生成當日記錄：

- **世界日誌**：以說書人口吻總結全谷當日大事（誰吵架了、下了雨、有人離開了）。
- **角色日記**：以角色第一人稱視角寫下他當天的所思所感（基於其記憶與情緒）。
- **價值**：
  - 讓玩家快速回顧錯過的劇情；
  - 累積成可閱讀／可分享的「故事書」；
  - 作為角色長期記憶的摘要來源。
- **可分享性**：日誌可匯出為圖文，方便玩家在社群分享自己角色的故事。

## 8. 多人與社交層（待確認方向）

> 此區涉及核心架構抉擇，建議先定方向再展開。見下方「待確認問題」。

- **共享世界 vs 個人世界**：所有玩家的角色活在同一個山谷？還是各自的私人山谷可互相串門？
- **角色互動**：不同玩家的角色相遇、合作、衝突、戀愛——這是社群病毒傳播的核心。
- **隱私邊界**：玩家**永遠**能看到自己角色的內心想法（見 3.5），但他人只能看到外顯行為——內心對其他玩家私有。是否允許開放「內心公開」給特定好友，可作為進階選項。

---

## 9. MVP 範圍建議（第一個可玩版本）

優先做出「能產生有趣故事」的最小閉環：

1. 單一山谷地圖 + 時間系統（可加速的遊戲日）。
2. 角色創建（性格 / 外觀 / 日常）+ 雲端內建 AI（先不開放 BYO Token）。
3. 3–8 個角色的自主行為 + 基本社交（對話、好感）。
4. 基礎記憶系統（記憶流 + 簡單反思）。
5. 1–2 種全局事件（天氣 + 一種天災）。
6. AI 每日日誌。
7. 一頁式觀察介面 + 回放。

**暫不做**：BYO Token、地端模型、多人共享世界、複雜經濟系統、戰鬥。

---

## 10. 開放設計問題（需要你決定）

1. **世界拓樸**：單一共享大世界，還是每位玩家擁有私人山谷？（影響伺服器與成本架構）
2. **角色死亡**：角色會死嗎？死亡是永久的還是可重生？這定義了情感重量。
3. **玩家影響力上限**：全局事件要不要有「神力值／冷卻」成本來防止濫用？
4. **公平性**：BYO Token（強模型）角色 vs 內建角色，如何避免課金碾壓？
5. **內容安全**：玩家自定義 AI 性格與自由對話，需要怎樣的內容審核與防濫用機制？
6. **變現模式**：訂閱（雲端額度）？角色／外觀售賣？還是純 BYO Token 的工具型產品？
